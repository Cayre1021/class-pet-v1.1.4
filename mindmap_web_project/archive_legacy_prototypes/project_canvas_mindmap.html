AS-IS BASELINE 单机 React+Electron

老版本使用动线全景

基于 LocalStorage 的单机模式，分流为 3 个主要独立入口。

PORTAL (`/`) 分流总入口

统一门户导航

  • 👨‍🏫 大屏展示：教室常态全班展示
  • 👑 教师管理：学籍名单、加扣分录入
  • 👦 学生查询：单人积分账单查看
⚠️ 缺陷：三大卡片孤立，缺乏数据概览与快速切换
TEACHER (`/admin`) 高频痛点集中区

教师工作台操作流

1. 名单导入：单条录入 / 多行文本批量粘贴
2. 加扣分动线： 必须先手动点击学生卡片 ➔ 再点击右侧加分项
3. 反馈：顶部弹出绿色 Toast + 屏幕中央全屏撒彩花
❌ 严重阻碍：无小组批量赋分，40人集体奖惩需机械点击40次！
BIG SCREEN (`/screen`) 大屏常态投影

班级大屏展示动线

• 全班网格平铺：卡片展示蛋/宠物、EXP与心情条
• 点击弹窗互动：弹出模态框，支持喂食、抚摸、陪玩
• AI 悬浮对话：右下角悬浮窗调用大模型生成宠物回复
❌ 痛点 1：宠物除升级外完全静止，缺乏生命状态机
❌ 痛点 2：撒花放屏幕中央，被奖惩学生未被高光聚焦
❌ 痛点 3：喂食气泡遮挡弹窗标题文字（实机 Bug）
STUDENT & DASHBOARD 个人端与统计

学生查询与数据大盘

• 学生查询 (`/student`)：选择姓名查看个人单宠与加扣分流水账单
• 仪表盘 (`/dashboard`)：班级总积分统计与 Top 5 排行榜
⚠️ 局限：单宠单实体绑定，满级后成长激励直接归零；无法带回家跨端查看
STORAGE ARCH 无后端

纯客户端 LocalStorage

  • 存储键：`class_pet_students:${accountKey}`
  • 跨标签页同步：`window.storage` 事件
  • 致命瓶颈：数据无法跨设备同步、易被清理丢失
CLIENT VOICE 来自一线兰老师录音

甲方改进诉求全景

针对课堂真实摩擦点，提出的 6 大核心改进方向与机制革新。

DEMAND 01 · 生产力 最高频痛点

批量操作支持

“第一个就是批量操作这个点比较麻烦，不能一个一个点...”
核心诉求：大班教学时，值日生、整组背诵、全班作业优秀需一键批量打分。
UX 目标：支持按小组、按学号段、全选或自定义多选。
DEMAND 02 · 成长感 正反馈断层

丰富宠物形态与进化感知

“升了个五六级、七八级、几十级还是那个鬼样子，变化太少了！”
核心诉求：数值升级必须伴随高频、显著的视觉变化与装扮解锁。
UX 目标：微等级积累 + 关键节点外观大变身 + 动态特效装配。
DEMAND 03 · 拟真生命 类 QQ 宠物

引入生理状态机与丰富互动

“类比 QQ 宠物，困了趴地上睡觉，渴了说‘我渴了’伴随动画动作...”
核心诉求：大屏常态挂机时宠物不能是死图，要自发生动表达。
UX 目标：困、渴、饿、兴奋等生理状态机 + 专属帧/骨骼动作反馈。
DEMAND 04 · 视线引导 有效 UI vs 无效 UI

升级仪式感与 C 位高光聚焦

“烟花撒给谁看？属于无效UI！应该把其他按平，就剩它在中间，烟花呼应C位！”
核心诉求：消除盲目全屏撒花，升级时做高对比度聚光灯效果。
UX 目标：全屏暗化 + 目标卡片放大居中 Spotlight + 精准呼应庆祝。
BREAKTHROUGH · 机制革新 兰老师方案

一人多宠 · 学科宠物博物馆

“不用卡控分数，满级了再挂物理宠、语文宠、数学宠，最后比谁宠物多！”
核心诉求：打破单宠满级天花板，支持多学科独立激励。
UX 目标：支持单学生挂载多个学科宠物 + 满级荣誉殿堂收集。
FUTURE · 进阶架构 云端同步

宠物带回家 & QQ 邮箱绑定

“学生带回家...数据库肯定是跑不了的，用 QQ 号码/邮箱随时在家里查看...”
核心诉求：数据脱离单机，支持学生在家端/家长端查看。
技术目标：设计 Cloud-Ready 数据契约与账号鉴权体系。
UX SOLUTION 01 批量矩阵操作台

教师工作台深度重构

  • 新增【小组矩阵 (Group Tabs)】与【值日排班预设】
  • 支持多选框、反选、按行按列一键批量赋分
  • 引入【即时撤销 Undo 浮条】，杜绝手抖误扣分
UX SOLUTION 02 Spotlight C位聚光灯

大屏高光时刻沉浸反馈

  • 升级/重大加分触发：全屏暗化压低其余卡片
  • 主角卡片平滑放大弹射至中央 (C-Spotlight)
  • 烟花粒子精准由主角向四周迸发，形成强荣誉感
UX SOLUTION 03 多宠博物馆系统

学科宠物与荣誉殿堂架构

  • 单学生支持绑定多个学科宠物卡槽（语/数/英/德育）
  • 满级宠物自动转入【个人博物馆】，解锁永久荣誉勋章
  • 排行榜从“单宠等级比拼”扩展为“满级宠物收集榜”
ARCH SOLUTION 04 Cloud-Ready 数据契约

云端数据库与跨端同步架构

  • 前端数据模型升级为 `StudentProfile` + `petMuseum[]`
  • 预留 `boundEmail` (QQ邮箱) 字段用于家庭端登录鉴权
  • 网络异步状态处理（Loading 骨架屏、提交防重、断网缓存）
