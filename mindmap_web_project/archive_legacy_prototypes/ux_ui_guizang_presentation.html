DIMENSION 01 · 逻辑与动线

UX 用户体验

核心关注：好不好用、流不流畅、解没解决问题

  • 任务链路闭环：前置条件、分支判断与状态流转

UI 用户界面

  • 品牌质感传达：排版调性、品牌色传达、微交互即时反馈

LITMUS TESTS THREE METHODS OF DISTINCTION 07 / 12
№ 01
黑白线框图测试

去掉所有色彩、投影与插画：

依然存在的是 UX（步骤几步、左右分栏、先点哪再点哪）；

彻底消失的是 UI（主色调、圆角值、阴影与描边质感）。

№ 02
提问动词测试

问 How it works 是 UX：
“为什么放这里？操作顺不顺？输错了如何引导？”

问 How it looks 是 UI：
“抓不抓眼球？排版是否拥挤？是否符合品牌调性？”

№ 03
挑刺争论焦点

争论操作效率是 UX 问题：
“太繁琐、找不到入口、容易误触”；

争论审美感官是 UI 问题：
“太素了、颜色不好看、字太小、不够高级”。

THE INTERSECTION SKELETON & INTERACTION PATTERNS 08 / 12
交界地带解析

“步骤条、紧凑表格、左右分栏”
到底属于 UX 还是 UI？

它们处于经典五层模型中的【框架/骨架层（Skeleton）】：

作为 UX 决策：决定“为什么选分栏”（左看右填减少跨页记忆负荷）、决定“回车连续跳行”（提高录入效率）。

作为 UI 表达：决定分栏是 1px 细灰线还是立体卡片，决定表头字阶比例与斑马纹色值。

CASE STUDY: ORDER ENTRY & APPROVAL THREE ARCHITECTURAL SOLUTIONS 10 / 12
VARIANT A · 防错稳健

向导步骤流 (Wizard)

将订单录入严格拆解为 3 步（客户 ➔ 明细 ➔ 审批人）。每一步聚焦单一任务与单向校验。

适用：新手、低频、容错要求极高
UI: 居中大卡片、步进条、明显 CTA
VARIANT B · 极速专业

高密网格流 (Grid)

类似 Excel 在线平铺表格，支持 Tab / Enter 键连续录入，行内即时校验并一键批量提交。

适用：熟练工、批量录入（效率+80%）
UI: 紧凑行高、快捷键栏、即时编辑框
VARIANT C · 对照决策

双栏工作台 (Split)

左侧陈列历史模版与物料库（可一键克隆），右侧实时表单并动态计算利润率与合规校验。

适用：需对照历史策略的复杂商务谈判
UI: 4:6 分割视图、联动侧抽屉面板
SAME BUSINESS LOGIC, VASTLY DIFFERENT UX 向上级与客户汇报商业与效率的权衡
CLIENT COLLABORATION METHODOLOGY TRANSLATION & DIAGNOSIS 11 / 12
实战方法论

如何将甲方反馈
转译为专业的 UX 重构方案？

  1. 需求转译（5 Whys）：剥离甲方的表层解法，挖掘背后的真实使用卡点。
  2. 圈定手术范围：判断是“局部节点动线微调”还是“全局信息架构重构”。
  3. 双轨差异化提案：同时输出【平滑改良版】（低学习成本）与【深度重构版】（极致效率）。
  4. 溯源结构汇报：以“问题 ➔ 根因 ➔ 方案权衡”汇报，建立专业话语权。
TRANSFORMATION EXAMPLE / 转译对照
甲方表层反馈：
“在首页加一个大红色醒目按钮！”
挖掘真实根因：
核心高频业务入口层级过深，认知检索耗时长。
专业 UX 重构解法：
提升信息架构优先级 + 顶部常驻快捷任务胶囊
