# TapNow Canvas 导出文件存放区 (Exports Directory)

本目录为 **TapNow Canvas MindFlow** 导出的所有交付物推荐存放位置。

---

## 📁 规范导出文件命名建议

| 文件类型 | 推荐命名格式 | 示例 | 说明 |
| :--- | :--- | :--- | :--- |
| **超清 PNG 图片** | `{项目名}_{清晰度倍率}_{日期}.png` | `AI影视工作流_2x_20260828.png` | 2x / 3x Retina 高清导图图片 |
| **矢量 SVG 图形** | `{项目名}_{日期}.svg` | `商业思维导图_20260828.svg` | 可用于 Figma / Illustrator 矢量无损导入 |
| **JSON 工程存档** | `{项目名}_snapshot_{时间戳}.json` | `系统架构决策树_snapshot_1724800000.json` | 可在画布中点击“导入 JSON”随时恢复 |

---

## 💡 提示
- 在画布页面点击右上角 **“导出图片 / 数据”**，浏览器下载的图片建议另存至本文件夹内以保持项目资产归档统一。
