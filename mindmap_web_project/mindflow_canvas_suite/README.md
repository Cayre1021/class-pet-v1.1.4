## 🚀 跨目录自由移动 `index.html` 的专属机制

我们特别为你实现了 **“无论 `index.html` 放到哪里都能正常使用”** 的路径自适应解析机制：

1. **即使将 `index.html` 单独拷贝或移动到桌面、下载夹或外接硬盘**：
   - 双击打开 `index.html`，点击顶部 **「偏好设置」**。
   - 在设置中的 **「画布编辑器关联路径」** 默认为：
     `file:///d:/Desk/ALL%20Vibe/new-class-pet/mindmap_web_project/mindflow_canvas_suite/canvas.html`
   - 你可以自由修改为当前画布文件所在位置。
   - 点击主页上的任意项目卡片或模板，系统都会通过智能路径解析器**准确跳转并打开画布**！
2. **实时自动保存与项目中心联动**：
   - 在画布中创作时，每次编辑或拖拽都会实时自动保存到本地项目注册表，并在顶部显示精准的自动保存时间（如：`已自动保存 14:20:15`）。
   - 点击「← 项目中心」或关闭页面，所有改动均会即时同步到主页工程看板中，绝不丢失。
   - 设置中提供 **「导出 JSON 备份」** 功能，可一键将所有脑图工程打包备份为单体 JSON 文件。

## 🖱️ 鼠标与手势交互指南

| 交互动作 | 触发区域 | 执行效果 |
| :--- | :--- | :--- |
| **鼠标左键长按框选 (Marquee)** | 空白画布区域 | 拉出蓝色半透明选框，批量选中矩形区域内的所有节点 |
| **鼠标右键单击 (Context Menu)** | 空白画布区域 | 弹出新建节点菜单（卡片、椭圆、方格、菱形、便签、胶囊、框架、创作块） |
| **鼠标右键单击 (Node Menu)** | 任意节点上方 | 弹出节点操作菜单（添加子分支、同级节点、切换形状/主题色、置顶、删除） |
| **鼠标右键单击 (Wire Menu)** | 任意连线上方 | 弹出关系菜单（编辑关系文字、切换曲线/折线/直线、开关流动光效、删除） |
| **节点锚点拖拽 (Port Drag)** | 节点边缘 4 个端口 | 拖出流光连线；松手至另一节点完成连接，松手至空白处自动生成子分支 |
| **鼠标滚轮 / 触控板捏合** | 全局视口 | 以鼠标当前所在位置为中心进行平滑缩放 (`15% ~ 300%`) |
| **空格键 + 鼠标左键拖拽** | 全局视口 | 平移移动整个画布视野 |

## ⌨️ 极速键盘快捷键列表

| 快捷键 | 功能描述 |
| :--- | :--- |
| `Tab` | 选中单节点时：**向右快速新建并自动连线子分支**（思维导图核心模式） |
| `Enter` | 选中单节点时：**向下快速新建同级分支** |
| `Ctrl + S` / `Cmd + S` | 立即手动保存当前画布与工程 |
| `Ctrl + Z` / `Ctrl + Y` | 撤销 (Undo) / 重做 (Redo) |
| `Ctrl + D` | 快速克隆复制当前选中的节点 |
| `Delete` / `Backspace` | 删除当前选中的节点或连线 |
| `V` / `H` | 切换为选择工具 / 抓手工具 |

## 📤 导出与交付规范

点击画布右上角 **「导出图片 / 存档」**：
1. **PNG 格式**：支持 1x 标清、2x 高清、3x 超清 Retina 分辨率，可选择暗色背景、纯白背景或透明背景；
2. **SVG 格式**：纯矢量代码，可无损导入 Figma、Illustrator 或嵌入网页；
3. **JSON 存档**：完整保留所有节点坐标、样式、连接拓扑与分支关系，方便随时恢复或分享给他人与 AI。
