## 📌 二、 7 大核心技术与设计规格细则

### 维度 1：画布核心交互与节点拓扑系统 (`canvas.html`)
1. **无限画布漫游与缩放**：
   - 鼠标滚轮以当前鼠标所在位置为中心进行平滑缩放（`15% ~ 300%`）；
   - 按住 `空格键 + 鼠标左键` 或使用抓手工具拖拽平移整个画布视野；
   - 右下角配备常驻全局导航小地图（Minimap），并显示节点总数与当前视口矩形框。
2. **多形态节点支持 (必须支持 8 种图形)**：
   - **主题卡片 (Card)**：标准业务卡片，带标题、副标题/内容与彩色状态角标；
   - **椭圆思维泡泡 (Circle)**：适合作为思维原点或发散核心；
   - **矩形模块方格 (Rect)**：适合作为架构系统组件与执行单元；
   - **菱形决策逻辑 (Diamond)**：适合条件判断与分支流向；
   - **随笔便签 (Sticky Note)**：仿真便签纸质感与折角；
   - **状态胶囊 (Pill)**：圆角标签与关键词；
   - **分组框架 (Frame)**：虚线容器，可框选容纳多个子节点；
   - **创作节点 (AI Prompt)**：代码与多模态参数卡片。
3. **连线系统 (Wires) 与拓扑关系**：
   - 每个节点四周提供 4 个端口锚点（Top / Right / Bottom / Left），鼠标悬停或拖拽时高亮；
   - 拖出连线：松手至另一个节点锚点即完成连接，松手至空白处**自动向该方向生成新子节点并连接**；
   - 连线样式支持：**平滑贝塞尔曲线 (Bezier)、正交折线 (Orthogonal)、直线 (Straight)**；
   - 连线支持双击标注关系文字胶囊（如“输入”、“派生”、“依赖”），支持动态流光波纹开关。
4. **关键鼠标与手势交互**：
   - **空处长按左键框选 (Marquee Selection)**：在空白处按住鼠标左键拉出半透明选框，批量选中矩形区域内的所有节点；
   - **空处单击右键**：弹出新建节点上下文菜单；
   - **节点上方单击右键**：弹出变换形状、更换主题色（青蓝/电光紫/翡翠绿/琥珀金/赤霞红/深空灰）、置顶、复制副本、删除节点菜单；
   - **连线上方单击右键**：弹出编辑关系文字、切换线型、切换流光、删除连线菜单。
5. **快捷键与思维导图一键扩展**：
   - `Tab`：选中单节点时向右快速新建并自动连线子分支；
   - `Enter`：选中单节点时向下新建同级节点；
   - `Ctrl + S`：立即保存；`Ctrl + Z` / `Ctrl + Y`：撤销 / 重做；`Ctrl + D`：克隆节点；
   - 顶部提供「一键整理 (Auto Layout)」按钮，自动按树状导图层次计算对齐排列。

### 维度 2：工程管理、主页看板与实时自动保存 (`index.html`)
1. **实时无感自动保存 (Auto-Save)**：
   - 在画布中进行任何节点移动、文本修改、连线连接或排版时，毫秒级防抖**自动保存至 `localStorage` 并同步更新公共项目注册表**；
   - 顶部状态栏显示精准时间戳（例如：`🟢 已自动保存 14:20:35`），并提供显式 `💾 保存` 按钮；
   - 点击「← 项目中心」时执行强制即时同步刷新，返回主页必定能立即看到新建与修改过的工程。
2. **新建即入库**：
   - 在主页点击「+ 新建画布」或任意预设模板时，立即分配唯一 ID 并将元数据（标题、节点数、修改时间）登记入库，绝不能出现返回主页找不到新建项目的情况。

### 维度 3：主页项目卡片「真实脑图动态 SVG 缩略图」
1. **所见即所得的卡片预览**：
   - 采用 **16:10 偏小矩形卡片网格**（3 列自适应响应式排列）；
   - 卡片上部集成 **轻量级动态 SVG 渲染引擎 (`renderProjectThumbnail`)**：

     - 动态计算包围盒（Bounding Box），自适应缩放呈现真实的脑图拓扑；
     - 包含网格暗纹、彩色连线与真实节点标题，用户在主页即可直观预览脑图脉络；
     - 新建的空白工程则展示细腻点阵与「空白画卷 · 点击开启创作」引导；
   - 鼠标悬停卡片时，平滑浮现极简「进入画布 ↗」小胶囊。

### 维度 4：视觉美学、排版与 WebGL 钛金流转背景
1. **拒绝花哨杂乱，回归高级极简主义**：
   - 严禁杂乱幼稚的伪插图与刺眼的高饱和渐变色；
   - 采用沉稳纯粹的黑白灰与暗色毛玻璃卡片（`rgba(14, 16, 20, 0.72)` + `backdrop-filter: blur(16px)`）。
2. **严格字号阶梯，告别字号偏小**：
   - 主标题：`Playfair Display / Noto Serif SC` 经典衬线大标题（36~48px）；
   - 卡片标题：`16px` 加粗清晰；正文简介：`13px`；元数据：`11px` 等宽。
3. **真实 GPU 级「钛金暗流」流转动效 (WebGL Holographic Dispersion)**：
   - 移植自顶级 WebGL 动态着色器（参考 `open-design-01-monocle.html` 的 `FS_DARK`）；
   - 具备液态钛金暗流、彩虹色散微扰与平滑流体矢量矩阵，60FPS 丝滑循环流动（**强调：是流体流动运转，绝非静态色彩渐变**）；
   - 鼠标滑动时实时激起指数衰减的流体涟漪波纹（`u_mouse` 互动）。
   - **GLSL 片段着色器核心源码**：
     ```glsl
     precision highp float;
     uniform vec2 u_resolution; uniform float u_time; uniform vec2 u_mouse;
     vec3 palette(float t, vec3 a, vec3 b, vec3 c, vec3 d) { return a + b * cos(6.28318 * (c * t + d)); }
     void main() {
       vec2 uv = gl_FragCoord.xy / u_resolution.xy;
       vec2 p = uv * 2.0 - 1.0; p.x *= u_resolution.x / u_resolution.y;
       vec2 m = u_mouse * 2.0 - 1.0; m.x *= u_resolution.x / u_resolution.y;
       float md = length(p - m);
       float mr = sin(md * 15.0 - u_time * 4.0) * exp(-md * 3.0); p += mr * 0.08;
       vec2 p0 = p;
       for (float i = 1.0; i < 4.0; i++) {
         p.x += 0.1 / i * sin(i * 3.0 * p.y + u_time * 0.4) + 0.05;
         p.y += 0.1 / i * cos(i * 2.0 * p.x + u_time * 0.3) - 0.05;
       }
       float r = length(p); float ang = atan(p.y, p.x);
       vec3 a = vec3(0.12, 0.12, 0.13); vec3 b = vec3(0.03, 0.04, 0.05);
       vec3 c = vec3(1.0, 1.0, 1.0); vec3 d = vec3(0.1, 0.2, 0.4);
       vec3 col = palette(r * 1.5 + p0.x * 0.5 + u_time * 0.1, a, b, c, d);
       float disp = sin(r * 25.0 - u_time * 1.5 + ang * 2.0) * 0.5 + 0.5;
       col += vec3(disp * 0.015, disp * 0.01, disp * 0.02);
       float hi = pow(sin(p.x * 4.0 + p.y * 3.0 + u_time) * 0.5 + 0.5, 8.0);
       col += hi * 0.08;
       vec3 base = vec3(0.05, 0.05, 0.06);
       col = mix(base, col, 0.85);
       gl_FragColor = vec4(col, 1.0);
     }
     ```

### 维度 5：节点输入体验与去 AI 味细节
1. **提示词交互体验优化**：
   - 节点默认提示词（如 `新主题卡片`、`思维原点`、`双击编辑内容...`）常态下保持 **半透明暗灰虚化质感**（`opacity: 0.45`）；
   - 鼠标点击输入框进入聚焦（focus）时，**默认提示词自动消失清空**，用户直接输入内容，无需手动按退格键；
   - 失焦（blur）时若未输入任何字符则智能恢复虚化提示词，若有输入则转为正常明亮正文显示。
2. **彻底去除 AI 味彩色渐变按钮**：
   - 右上角「导出图片 / 存档」等操作按钮采用黑白纯色微光现代极简按钮（`bg-white text-black hover:bg-slate-200`），绝不使用浮夸彩虹渐变。
3. **品牌独立性**：
   - 项目全称采用 **MindFlow Canvas · 智绘导图**，严禁残留任何第三方平台品牌词。

### 维度 6：跨目录自由移动机制与文件系统鲁棒性
1. **独立移动 `index.html` 依然可用**：

2. **图标常态全生命周期保全**：
   - 确保 `lucide.createIcons()` 在 `DOMContentLoaded`、空列表分支、模态框弹出等全生命周期均被可靠调用，**无论用户清空项目或刷新浏览器，全站所有图标绝不丢失**。

### 维度 7：多格式导出交付与 AI Agent 接入规范
1. **多维度导出 (`html2canvas` & 矢量生成)**：
   - **PNG**：支持 1x / 2x / 3x Retina 超清分辨率，支持暗色、纯白、透明 3 种背景；
   - **SVG**：纯矢量代码导出，可直接导入 Figma / Illustrator；
   - **JSON**：完整拓扑工程存档，支持一键备份与导入恢复。
2. **Agent 自动化开发规范 (`AGENT_INSTRUCTIONS.md`)**：
   - 必须提供树状导图的坐标排版算法公式：
     - 水平层级间距：$\Delta X = 120\text{px} \sim 160\text{px}$；
     - 垂直同级间距：$\Delta Y = 30\text{px} \sim 50\text{px}$；
     - 父节点垂直居中公式：
       $$Y_{\text{parent}} = \frac{Y_{\text{child\_first}} + Y_{\text{child\_last}}}{2}$$
