# 课堂教学时序场景与教育心理学 UX 防线规范 (Supplementary Analysis)

## 一、 课堂全天候使用场景与交互频次时序表

为了让第四阶段的 UX 设计精准契合一线教师与学生的真实作息，梳理出以下 5 大典型时序场景：

| 教学时序场景 | 发生时间与时长 | 核心使用角色 | 交互模式与核心诉求 | 推荐的 UX 动线机制 |
| :--- | :--- | :--- | :--- | :--- |
| **场景 A：早晨值日 / 考勤打卡** | 07:40 - 08:00 (约2分钟) | 班主任 / 值日班长 | **批量操作**：快速给负责早读、打扫卫生的 6~8 人集体赋分 | 教师端使用【值日组一键多选】，1 秒完成集体 +5 分 |
| **场景 B：随堂授课与即时提问** | 08:30 - 11:50 (5-10秒/次) | 任课教师 (语/数/英) | **高频极速**：讲课过程中快速奖励积极发言学生，不可打断课堂节奏 | 教师端悬浮快捷键或单手点选，轻量 Toast 反馈，不阻断大屏 |
| **场景 C：40分钟常态黑板挂机** | 课堂全时段 (持续40分钟) | 全班学生 (被动感知) | **拟真生命力**：大屏作为环境背景，不能是死板静态图 | 开启【QQ宠物式生理状态机】：随机打瞌睡、揉眼、冒气泡 |
| **场景 D：周五结业 / 荣誉时刻** | 周五下午 (5-10分钟) | 班主任与全班集体 | **仪式感与全屏高光**：宣布本周升级/满级退役的宠物 | 触发【C位聚光灯 (Spotlight)】与入驻个人博物馆仪式 |
| **场景 E：周末家庭端查阅** | 周末家中 (不限) | 学生与家长 | **跨设备漫游**：学生向家长展示成长轨迹与积分账单 | 通过绑定的账号/邮箱登录查看个人博物馆与徽章 |

## 二、 奖惩教育心理学 UX 防线规范

在 K-12 教学环境中，积分系统不仅是管理工具，更是心理激励工具。必须在 UX 层面建立严格的**展示分级机制**：

```
                    ┌──────────────────────────────────────┐
                    │      积分与行为触发 (教师端发起)      │
                    └──────────────────┬───────────────────┘
                                       │
                ┌──────────────────────┴──────────────────────┐
                ▼                                             ▼
        【正向行为 (加分/升级)】                       【负向行为 (扣分/违纪)】
        - 课堂发言、作业优秀、助人                     - 迟到、未交作业、扰乱纪律
                │                                             │
                ▼                                             ▼
       【大屏端公开广播策略】                         【大屏端隐私保护策略】
      - 全屏 C 位聚光灯放大 (Spotlight)             - ❌ 严禁全屏弹窗播报学生姓名
      - 烟花粒子精准迸发                             - 仅在被扣分卡片局部显示微弱流汗动效
      - 强情绪价值，树立正面榜样                     - 详细扣分账单仅教师后台与个人端可见
```

### 1. 为什么必须执行“负向行为大屏弱化”？
* **避免公开羞辱（Public Shaming）**：如果在大屏上大张旗鼓地播报“张三 课上讲话 扣5分”，会直接摧毁学生的自尊心，导致其破罐子破摔、产生对系统的逆反心理。
* **降级保护原则（No Demotion）**：扣分仅扣除当前级别的 EXP，**绝对不扣除宠物已经解锁的形态和外观配件**。经验扣到 0 时，宠物仅显示“困乏/需要补充能量”状态，不剥夺既得荣誉。
