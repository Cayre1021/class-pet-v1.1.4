## 一、批量赋分流程（核心痛点解决）

### 1.1 当前痛点
旧版要求"先选人后加分"，40人班级需要点击40次，效率极低。

### 1.2 优化方案

**流程A：多选后赋分（推荐）**
```
1. 教师在学生列表勾选多个学生（支持Shift连选、Ctrl点选）
2. 顶部显示"已选择 N 人"
3. 点击右侧行为按钮（如"+5 认真听讲"）
4. 弹出确认对话框显示：
   - 受影响学生列表
   - 行为规则
   - 总计分值变化
5. 确认后批量提交
6. Toast提示"成功为 N 名学生加分"
```

**流程B：小组快选（V1.1）**
```
1. 顶部增加"小组筛选"下拉
2. 选择"第一组"自动勾选该组所有学生
3. 后续流程同流程A
```

### 1.3 交互细节

- 选中状态：卡片高亮边框 + 复选框勾选
- 全选按钮：列表顶部"全选/取消全选"
- 批量上限：单次最多50人（防止误操作）
- 确认弹窗：必须显示受影响学生，不能静默提交

## 二、Undo操作流程（V1.1优先）

### 2.1 触发条件
- 最近3分钟内的赋分操作
- 未被后续操作覆盖的批次
- 操作批次完整保留在数据库

### 2.2 Undo流程
```
1. 赋分成功后，右下角显示Undo浮窗（3分钟倒计时）
2. 点击"撤销"按钮
3. 确认对话框："确认撤销对 N 名学生的操作？"
4. 确认后回滚该批次所有变更
5. Toast提示"已撤销操作"
```

### 2.3 数据约束
- Undo仅回滚积分和经验
- 已触发的升级/进化不回滚（避免学生看到宠物退化）
- 记录Undo操作本身到日志

## 三、学生导入流程

### 3.1 Excel导入
```
1. 点击"批量导入"按钮
2. 选择Excel文件（.xlsx/.xls）
3. 系统识别列：学号、姓名、分组（可选）
4. 预览导入数据表格
5. 冲突处理：
   - 学号重复：提示跳过或覆盖
   - 缺少学号：自动生成（01, 02, ...）
6. 确认导入
7. 显示导入结果统计
```

### 3.2 文本导入
```
1. 选择"文本导入"
2. 粘贴文本，每行一个学生（姓名或"学号 姓名"）
3. 自动解析：
   - "01 张三" → 学号01，姓名张三
   - "张三" → 自动生成学号，姓名张三
4. 预览后确认导入
```

## 四、等级与规则配置流程

### 4.1 等级阈值设置
```
【默认配置】
总等级：20级
阶段节点：Lv0(蛋) → Lv1 → Lv4 → Lv8 → Lv13 → Lv20(满级)

【修改流程】
1. 点击"等级配置"
2. 设置"最大等级"（建议10-50）
3. 设置各阶段经验阈值
4. 预览进度曲线图
5. 保存配置（仅影响未来升级，不回滚历史）
```

### 4.2 行为规则管理
```
【预设规则】
正向：+5 认真听讲、+3 作业优秀、+10 考试进步
负向：-2 作业未交、-3 违反纪律

【自定义规则】
1. 点击"添加规则"
2. 填写：
   - 规则名称
   - 分值（正数或负数）
   - 行为类型（正向/负向）
   - 是否常用（显示在快捷按钮）
3. 保存后自动出现在赋分按钮组
```
