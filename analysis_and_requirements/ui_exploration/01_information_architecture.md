## 一、核心用户与使用场景

### 1.1 用户角色矩阵

| 角色 | 主要设备 | 核心任务 | 使用频率 | 关键痛点 |
|------|---------|---------|---------|---------|
| **教师** | Windows PC | 班级管理、学生导入、快速赋分、规则配置 | 每日多次 | 批量操作效率低、误操作无Undo |
| **大屏** | 教室投影/电脑 | 持续展示全班宠物、响应升级庆祝 | 全天常驻 | 升级时主角失焦、缺少生命力动态 |
| **学生** | 个人查询端 | 查看个人宠物、成长记录、多宠管理 | 课间/课后 | 满级后失去动力、无法带回家 |

### 1.2 核心场景流程

```
【首次使用】
启动应用 
  → 创建本地账号（学校/班级/教师/密码）
  → 自动登录进入主页

【日常启动】
启动应用 
  → 自动恢复上次登录账号
  → 直接进入主页

【切换账号】
主页账号菜单 
  → 切换账号
  → 选择账号 + 输入密码
  → 进入对应班级
```

## 三、核心页面信息层级

**P2 - 详情面板可见**

- 互动CD状态
- 心情值
- 操作历史

### 3.2 教师操作台 - 信息优先级

## 四、状态与数据流

### 4.1 核心业务状态

```
【学生状态】
- 基础信息：学号、姓名、分组、备注
- 积分状态：总经验、当前等级、超额经验
- 宠物状态：拥有宠物列表、当前展示宠物
- 互动状态：各互动CD时间、今日互动经验

【宠物状态】
- 基础信息：宠物ID、学科绑定、创建时间
- 成长状态：当前阶段、可进化标记、满级标记
- 视觉状态：形象资源ID、配饰列表
- 互动状态：上次互动时间、心情值

【操作状态】
- 批次信息：操作ID、时间戳、操作者
- 受影响学生：学生ID列表
- 操作内容：行为规则ID、分值、备注
- 可撤销标记：是否支持Undo
```

### 4.2 页面间数据传递

```
主页 → 学生大屏
  传递：当前班级ID、学生列表

主页 → 教师操作台
  传递：当前班级ID、权限标识

操作台 → 大屏
  触发：赋分事件、升级事件、C位庆祝

大屏 → 详情
  传递：学生ID、宠物列表、互动权限
```
