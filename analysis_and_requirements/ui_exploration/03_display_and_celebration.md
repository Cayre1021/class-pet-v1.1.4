## 一、大屏卡片设计

### 1.1 卡片信息层级

```
┌─────────────────────────┐
│  [可进化]  Lv.8    🐱×3 │  ← 状态标签 + 等级 + 宠物数
├─────────────────────────┤
│                         │
│      [宠物形象]         │  ← 当前展示宠物（学科：语文）
│                         │
├─────────────────────────┤
│  张三  01号              │  ← 姓名 + 学号
│  ████████░░ 80/100      │  ← 经验进度条
│  心情：开心 😊            │  ← 状态气泡（可选）
└─────────────────────────┘
```

### 1.2 卡片状态变体

**常规状态**
- 白色背景，浅灰边框
- 宠物居中，适度留白

**可进化状态**
- 顶部金色"可进化"标签
- 卡片轻微呼吸光效
- 点击触发进化确认

**满级状态**
- 顶部紫色"满级"标签
- 卡片金色边框
- 超额经验显示为"+50 extra"

**选中状态（操作台联动）**
- 蓝色高亮边框
- 轻微缩放强调

## 二、C位庆祝流程（核心体验改进）

### 2.1 设计原则
> 甲方核心诉求：**烟花必须让观众知道在庆祝谁**

### 2.2 普通升级庆祝

```
【触发条件】
学生达到视觉阶段节点（Lv1 → Lv4 → Lv8等）

【动画流程】
1. 目标学生卡片从网格位置飞升到屏幕中央（0.3s）
2. 其他卡片保持位置，透明度降至30%
3. 中央卡片放大1.5倍，显示：
   - 学生姓名 + 学号
   - "恭喜升级到 Lv.X！"
   - 新形态宠物形象
4. 卡片周围小范围彩纸飘落（2s）
5. 自动或点击关闭后，卡片飞回原位（0.3s）
6. 其他卡片透明度恢复100%
```

### 2.3 最终满级庆祝

```
【触发条件】
学生首次达到最高等级（Lv.20）

【动画流程】
1. 全屏暗化至70%黑色蒙层
2. 目标学生卡片居中放大2倍
3. 显示满级特效：
   - 金色光环围绕宠物
   - "★ 满级成就达成 ★"
   - 学生姓名 + 最终形态
4. 烟花从卡片四周向外扩散（3-5s）
5. 底部文案："[张三] 成为首位满级大师！"
6. 3秒后自动关闭或点击跳过
7. 恢复大屏网格
```

### 2.4 技术约束

- 同时只处理一个庆祝事件
- 事件队列：多个升级按顺序播放
- 支持"跳过"按钮（教师权限）
- 庆祝期间不响应其他交互

### 3.3 互动反馈

```
【点击互动按钮】
1. 按钮禁用，显示CD倒计时
2. 宠物播放对应动作（如有动态资源）
3. 随机显示气泡文案：
   - "谢谢你的关心！"
   - "好开心呀~"
   - "感觉精力充沛！"
4. 随机获得0-2点经验（受规则约束）
5. Toast提示"互动成功，获得1点经验"
```

## 四、多宠物管理

### 4.1 学科宠物切换

**大屏卡片默认显示**
- 第一只创建的宠物
- 或教师/学生手动设为"展示宠物"

**详情面板切换**
```
1. 顶部Tab显示所有宠物：
   [语文🐱Lv.8] [数学🐶Lv.3] [英语🦊Lv.1]
   
2. 点击Tab切换当前宠物
3. 下方互动区和经验条动态更新
4. 每个宠物独立CD和互动记录
```

### 4.2 新宠物创建流程

```
【触发条件】
任意宠物达到满级（Lv.20）

【创建流程】
1. 详情面板显示"解锁新宠物"按钮
2. 点击后弹出学科选择：
   - 预设：语文、数学、英语
   - 自定义：输入学科名称
3. 选择学科后生成新的宠物蛋
4. 新宠物从Lv.0开始成长
5. 满级宠物继续显示，可继续互动
```

## 五、大屏工具栏设计

### 5.1 工具栏布局

```
┌────────────────────────────────────────────────┐
│  班级宠物大屏  |  排序：[学号▼] [等级] |  🔍搜索  │
│  实验小学三年二班  |  在线 ●  |  [全屏]  [设置] │
└────────────────────────────────────────────────┘
```

### 5.2 排序逻辑

**学号排序（默认）**
- 01, 02, 03... 升序
- 班级花名册顺序

**等级经验排序**
- 优先按等级降序
- 等级相同按经验降序
- 经验相同按超额经验降序
- 完全相同按学号升序

**搜索过滤**
- 实时搜索学生姓名或学号
- 支持拼音首字母（如"zs"匹配"张三"）
- 未匹配学生卡片灰显或隐藏
