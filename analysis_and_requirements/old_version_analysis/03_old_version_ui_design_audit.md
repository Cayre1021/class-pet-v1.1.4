# 班级电子宠物平台 (老版本 v0.2.0) · UI 视觉设计与组件体系审计

## 一、 视觉设计规范（Duolingo 风格）审计

### 1. 色彩体系 (Dopamine Palette)
- **品牌主色**：
  - 多邻国绿：`var(--color-duo-green)` (`#58CC02`) / 深绿 (`#46A302`)
  - 天空蓝：`var(--color-duo-blue)` (`#1CB0F6`) / 深蓝 (`#1899D6`)
  - 活力黄：`var(--color-duo-yellow)` (`#FFC800`) / 深黄 (`#E5A400`)
  - 警示红：`var(--color-duo-red)` (`#FF4B4B`) / 深红 (`#EA2B2B`)
  - 尊贵紫：`var(--color-duo-purple)` (`#CE82FF`) / 深紫 (`#A562D6`)
- **背景与中性色**：`bg-neutral-100` (`#F5F5F5`), `text-neutral-800` (`#262626`)
- **评估**：色彩明快亲和，符合低龄及中小学课堂的活泼氛围；但在严肃大屏汇报或高年级教学场景中，部分高饱和色彩略显低幼。

### 2. 控件形态与质感表现
- **圆角规范**：全量采用超大圆角 `rounded-[2rem]` (约 32px) 和 `rounded-3xl`，视觉软萌 Q 弹。
- **立体按压厚度感 (3D Push Button)**：
  - 采用底部加厚阴影模拟实体积木按钮（如 `shadow-btn-blue`），点击时产生向下位移 `translate-y-1` 的力学反馈。
- **动效引擎**：
  - 全局集成 `framer-motion` 弹簧刚度阻尼动画 (`type: "spring", stiffness: 200, damping: 20`)。

## 二、 宠物形象资产与视觉层叠审计

```
[当前宠物形象资产分布]
├── 8 类基础动物 (Bird, Bunny, Cat, Deer, Dog, Fish, Fox, Hamster)
└── 4 个进化阶段 PNG:
    ├── stage1: 幼态/初始态
    ├── stage2: 成长幼体 (Lv 3 解锁)
    ├── stage3: 进阶形态 (Lv 6 解锁)
    └── stage4: 终极形态 (Lv 8 解锁)
```

### 现存视觉与资产设计缺陷：
1. **等级跨度过大导致“长期静态”**：
   - 满级动辄 50~100 级，但视觉素材只有 4 张静态图，绝大多数升级（如 Lv10 升到 Lv20）在视觉形态上没有任何变化，导致用户产生“升到几十级还是那个鬼样子”的挫败感。
2. **盲盒特效（Accessory Effects）生硬悬浮**：
   - 皇冠 👑、小翅膀 ✨、墨镜 🕶️ 等盲盒特效在老版本中是直接通过 emoji / 绝对定位硬贴在容器上方，容易与不同体型的宠物产生穿模、比例失调。
3. **缺乏状态机帧动画（State Animations）**：
   - 目前只有 CSS `scale` / `rotate` 的简单摇晃，没有针对“睡觉/打哈欠/眨眼/吃东西”的精细帧动画或骨骼动画。
