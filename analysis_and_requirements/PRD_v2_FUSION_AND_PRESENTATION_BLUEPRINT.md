## 一、 项目背景与重构目标

“班级电子宠物平台”是一款结合游戏化养成与课堂管理的教育工具。
- **老版本痛点**：单机 LocalStorage 存储不稳定、单人单宠满级后激励失效、教师缺乏小组批量赋分、大屏宠物静止缺乏生命力、升级烟花全屏盲目撒花缺乏视觉焦点。
- **v2.0 重构目标**：
  1. **极速生产力**：引入【小组矩阵批量赋分】与【即时 Undo 撤销】，使 40 人集体赋分在 2 次点击内完成；
  2. **拟真生命力**：大屏引入【QQ 宠物式生理状态机】，常态挂机自发打瞌睡、伸懒腰、冒气泡；
  3. **C 位高光聚焦**：升级与重大加分触发【全屏暗化 + 目标放大居中 + 精准烟花】；
  4. **一人多宠博物馆**：落实兰老师提议，支持挂载多个学科宠物（语/数/英/综合），满级进入个人荣誉博物馆；
  5. **本地 Docker 架构**：后端与数据库采用本地 Docker 一键运行，数据持久安全，为远期上云预留同构标准。

## 三、 五大核心页面的具体呈现与交互规格

### 3.1 统一门户导航页 (`/` Portal)
* **页面定位**：全系统分流枢纽与班级状态概览。
* **具体呈现规划**：
  * **顶部状态栏**：展示当前教师班级名称（如“三年级二班 · 兰老师”）、本地 Docker 数据库连通状态；
  * **三大核心入口卡片**：
    1. **🖥️ 班级大屏 (Habitat)**：实时显示当前在屏宠物总数与平均健康度；
    2. **📋 教师工作台 (Console)**：突出“小组批量矩阵赋分 / 名单管理”；
    3. **🏛️ 个人成长博物馆 (Museum)**：突出“出战宠物 / 荣誉殿堂 / 积分账单”。

---

### 3.2 教师工作台 (`/admin` Teacher Panel) —— 【核心解决批量操作】
* **页面定位**：教师高频打分与班级管理主操作台。
* **具体呈现规划**：
  * **左侧：多维学生选择矩阵（双模一键切换）**：
    * **【小组视图 (Group Tabs)】**：顶部设“全部”、“第1组”、“第2组”、“第3组”、“值日组”标签，**点击标签 1 秒完成 6 人批量选中**；
    * **【网格视图 (Grid)】**：每个学生卡片右上角带独立复选框，支持按住 Shift 连续多选、一键反选与全选；
  * **右侧：学科分类与快捷赋分面板**：
    * **学科切换器**：顶部常驻【综合 / 语文 / 数学 / 英语】胶囊切换，加分直接计入对应学科宠物；
    * **行为标签库**：区分正向行为（绿色药丸）与负向扣分（浅红药丸）；
    * **【即时撤销 Undo 浮条】**：任何加扣分操作后，底部弹出 5 秒倒计时浮条“已给张三等 6 人 +5 分 ［↩ 撤销］”；
  * **名单管理**：支持从 Excel 或文本按行复制粘贴批量导入，并可快捷指定默认分组。

---

### 3.3 班级大屏展示 (`/screen` Big Screen) —— 【核心解决生命力与C位聚焦】
* **页面定位**：教室一体机/黑板投影常态展示，构建沉浸式班级宠物生态圈。
* **具体呈现规划**：
  * **1. 常态挂机：QQ 宠物拟真生态圈（Living Habitat）**：
    * 宠物每隔 30~60 秒自动触发随机生理状态机（无需人工点击）：
      * 💤 *困了/乏了*：宠物闭眼趴在卡片上起伏打呼噜；
      * 💧 *渴了/饿了*：头顶冒出半透明小气泡（“想喝水了～”、“需要投喂”）；
      * ✨ *开心/活泼*：轻微摇晃、向全班眨眼；
  * **2. 高光时刻：C 位聚光灯系统 (Spotlight Celebration Engine)**：
    * 触发升级或重大表扬时：
      1. **全屏暗化**：大屏背景其余卡片下沉并压暗 70%；
      2. **主角飞升**：被加分学生的宠物卡片平滑放大弹射至屏幕正中央；
      3. **精准烟花**：金色彩花由主角卡片向外爆发，展示全新解锁形态与称号；
  * **3. 弹窗重构（修复气泡遮挡 Bug）**：
    * 弹窗改为左右分栏（左侧展示大幅动态宠物，右侧展示互动按键与气泡对话），文字绝对不重叠。

---

### 3.4 学生查询与多宠博物馆 (`/student` & `/museum`) —— 【核心解决一人多宠】
* **页面定位**：学生独立查看个人成长、切换学科宠物与荣誉展示。
* **具体呈现规划**：
  * **出战主宠区 (Active Pet Card)**：展示当前选定学科的在养宠物（如“小狐狸 · 语文宠物 Lv.7”）；
  * **学科切换器**：可一键切换查看自己的数学宠、英语宠成长进度；
  * **荣誉殿堂 / 个人博物馆 (Pet Museum)**：
    * 满级（如 Lv.10）退役的宠物陈列于展厅，佩戴金色勋章与毕业日期；
    * 支持“领取新学科宠物蛋”，永远保持持续成长的驱动力；
  * **成长账单**：清晰呈现每日正负向行为明细与积分走势图。

---

### 3.5 班级数据大盘 (`/dashboard`)
* **页面定位**：班级整体学风与数据可视化。
* **具体呈现规划**：
  * 班级总积分、各学科积分雷达图、满级宠物收集榜（取代单一等级榜）。

## 四、 本地 Docker 架构与 API 接口契约总览

所有服务以本地 `docker compose up -d` 一键拉起，数据保存在本地 Docker 卷中：

| 功能模块 | API Endpoint | 方法 | 请求参数概要 (Payload) | 作用 |
| :--- | :--- | :---: | :--- | :--- |
| **班级学籍** | `/api/students` | `GET` | `?accountKey=xxx` | 拉取全班学生、分组与当前主宠数据 |
| **批量导入** | `/api/students/batch-import` | `POST` | `{ students: [{ name, group, ... }] }` | 批量录入学生名单 |
| **批量赋分** | `/api/scores/batch` | `POST` | `{ studentIds: string[], ruleId, subject, points }` | 一键为单人或整组打分 |
| **撤销操作** | `/api/scores/undo` | `POST` | `{ logId: string }` | 一键撤销上次误操作 |
| **大屏状态** | `/api/screen/habitat` | `GET` | - | 获取大屏全员状态机数据 |
| **实时广播** | `/api/screen/events` | `SSE/WS` | - | 实时推送 C 位聚光灯与加分动画事件 |
| **多宠博物馆** | `/api/students/:id/museum` | `GET` | - | 获取学生在养与已退役满级宠物列表 |

## 五、 老版本数据平滑迁移与兼容规范

在初始化或首次启动时，系统自动执行 `Data Migration Adapter`：
1. 检测 LocalStorage 中旧版单宠数据；
2. 自动将其封包为 `StudentProfile` 下的第 1 只【综合学科主宠】；
3. 保证老用户升级后数据**零丢失、零报错**。
