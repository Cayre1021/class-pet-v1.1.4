## 三、本轮发现的缺陷与处置

| 缺陷 | 证据 | 处置 |
|---|---|---|
| **撤销后重启，被撤销的加分被内存缓存回写、重新生效** | 集成测试旧探针：`dbAfterUndo=15 → dbAfterRestart=20`；根因 `classpet_core.js` 的 `Math.max(内存,库)` 合并 + 回写，且撤销未同步缓存 | **已修**：`v3UndoLast` 成功后丢弃陈旧名单缓存（`_v3DropStaleRosterCache`），下次读取以库为准；集成测试 [4] 改为硬断言（15→15），现 38/38 无告警 |
| JSON 备份被写成 UTF-8 BOM，`JSON.parse` 直接失败 | 真下载产物 3636 字节，BOM=true | **已修**（批次 5）：JSON 无 BOM、CSV 保留 BOM |
| CSV 导入走 `importStudents` 会整班删除重建，漏行即删学生 | 代码路径 + 语义 | **已修**（批次 4）：改逐人 `saveStudent` upsert，且写前拦截学号重复 |
| 42 人演示名单被写进真实班级库 | 构造期写调用 42 次 | **已修**（批次 3）：`isDemoRoster` + 签名识别，现 0 次 |

## 四、未验证（不写成通过）

1. **真机人工验收**：投影 3 米可读、触屏热区、双屏投屏、音效听感、画面观感——本线无图像/音频能力，只保证几何与数据。
2. **原生文件对话框**：CSV/JSON 导入用 `DataTransfer`/`FileReader` 等价替代，未在真机点「打开文件」。
3. **`storage` 跨文档同步**：`file://` 下 Chromium 不派发该事件，实现属尽力而为，无运行时证据。
4. **小分辨率**：1280×720 下台账 7 列与 13 条规则按钮的几何未逐个测（1440×900/1920×1080 已测）。
5. **真实数据态的逐帧动画**：pulse/shimmer 等只在演示态与逻辑层验证。
6. **88 人真实班级的端到端**：E2E 用 2–4 人的临时库副本，88 人只做过读取与复算（`test_v3_real_db`）。
7. **打包产物**：未执行 `npm run dist:win`，未验证安装包内页面/资源路径（批次 1 已静态确认 `src/**/*` 在 `build.files` 内）。
