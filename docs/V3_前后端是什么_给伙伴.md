# 给伙伴：这个项目的"前后端"到底是什么

> 一句话：**我们没有 Web 后端，没有 HTTP 接口，也没有端口。** 这是 Electron 单机应用，"后端"= 主进程 + 本地 SQLite。

## 一、三层结构

| 层 | 位置 | 干什么 | 类比 |
|---|---|---|---|
| 渲染层（前端） | `electron-app/src/*.html` + `classpet_core.js` | 界面、交互、动效 | 前端 |
| 桥（接口契约） | `electron-app/preload.js` → `window.electronAPI` | **唯一**能力面：14 个 db 方法 + 窗口/同步方法 | API 网关 |
| 主进程（后端） | `main.js`（IPC 路由）+ `sqlite_service.js`（sql.js/WASM）+ `database/classpet.sqlite` | 收请求、写 SQL、持久化 | 后端 + 数据库 |

没有 express / koa / fetch，`dependencies` 里只有 `sql.js`。所以别去找 `/api/*`，也没有 400x/500x，错误是靠 IPC 的 reject / 返回值表达的。

## 二、一次"加分"实际怎么走

```
老师点 +3
 → electronAPI.db.recordScore(payload)          （渲染层，preload 暴露）
 → ipcRenderer.invoke('db:recordScore', payload) （桥）
 → ipcMain.handle('db:recordScore', ...)         （主进程 main.js）
 → sqliteService.recordScore(...)                （数据层）
 → 写 score_entries / score_operations / 更新 pets.exp、pets.level
 → 返回结果 → 教师台弹 Toast
 → 主进程 broadcast-sync → 大屏 onBroadcastSync() → 重渲染
```

## 三、所以"前后端对齐"对的到底是什么

**界面上的每个可点元素、每个展示字段，能不能对上一个 electronAPI 方法、一个参数结构、一个返回结构、一张表的列。**

| 界面元素 | 对应方法 | 对应数据 |
|---|---|---|
| 赋分按钮 +1/+2/+3 | `db.recordScore(payload)` | `score_entries`/`score_operations`，改 `pets.exp/level` |
| 撤销上一笔 | `db.undoScore(operationId)` | 回滚 `score_operations` |
| 新增/编辑学生 | `db.saveStudent({student,classId})` | `students` |
| 学生卡片等级/阶段 | `db.loadAllState(classId)` | `pets.level` + `class_level_thresholds` + `class_visual_stages` |
| 破壳 | `db.hatchPet(payload)` | `pets.visual_stage` |
| 台账 | `db.getStudentAuditLogs(studentId)` | `score_entries` |
| 阈值设置 | `db.saveThresholds(thresholds,stages,classId)` | `class_level_thresholds`/`class_visual_stages` |
| 自定义规则 | `db.saveBehaviorRules(rules,classId)` | `behavior_rules` |

**对不上的那部分，就是"缺口"**：改前端适配 / 改数据层补字段 / 产品确认不做，三选一。

## 四、你上手会立刻撞到的三件事

1. **V3 三页没有引 preload。** 双击打开时 `window.electronAPI` 是 undefined，所以它们现在只能跑模拟数据。集成时必须由 `main.js` 用 `loadFile` 加载页面（那里默认注入了 preload），不能再用浏览器直接开。
2. **教师台的「学生大屏」是 `<a target="_blank">`。** 但 `main.js` 里 `setWindowOpenHandler(() => ({action:'deny'}))` 把新窗口全部拒了 —— 打包后这个链接**是死的**。要改成调 `electronAPI.openDisplayWindow()`（它实际是单窗口内切页）。
3. **数据结构对不上。** 库里是 0–20 级 + 阈值表 + 每科一只宠物（`pets.subject_id`）+ `visual_stage` 直接给形态；原型写死 9 级、单学科、用 `ceil(level/2)` 自己算阶段。

## 五、第一步做什么（三步，别铺开）

1. 读 `preload.js`（10 分钟能读完），把 14 个方法抄成一张表：方法名 / 入参 / 返回 / 失败情形。
2. 拿教师台对着这张表逐个标：**每个按钮、每个展示字段对应哪个方法或字段**；标不出来的写进"缺口"。这就是《前后端对齐表》。
3. 用**隔离测试库**（`Open-ClassPet-Test.cmd`）接通一条最小链路：
   `loadAllState` → 渲染真实名单 → 点 +3 → `recordScore` → `broadcast-sync` → 大屏刷新。
   这条通了，再横向铺开其它按钮。
