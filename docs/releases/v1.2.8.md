# v1.2.8 · 2026-11-20

## 修复（两路"老师动线"审计后补齐）

**数据安全**
- **备份可以跨班/换电脑还原了**：以前把旧班备份导进新班必报 `UNIQUE constraint failed`（规则/学生 id 是全局主键）。
  现在同班还原保持原 id 不変（台账引用不断），跨班才自动加班级前缀；**还原前自动把现场备份一份**（`.bak-<时间戳>`）。
- **写盘改原子写**（先写 .tmp 再 rename），降低断电把库写坏的风险。

**会让老师卡死的**
- **解锁后的科目能正常赋分了**：老班级学生缺某科宠物行时，以前报 `NO_PET_FOR_SUBJECT:subj_math`（英文、无出路），
  现在会自动补一条蛋行再赋分。
- **解锁资格改按经验阈值判定**：不再读陈旧的 `pets.level`，避免"界面说满级、系统说没满级"，也避免一次导入就把资格抹掉。
- **「数据与设置 → 唤醒新学科」**：以前只有一次性弹窗，点"稍后再说"就再也找不到解锁入口；现在菜单里随时可开，
  没有候选时也会说明"把已解锁科目练到 Lv.20 满级"的条件。
- **删掉中间一条规则后再新增不再失败**（以前生成的下标 id 会撞主键，报英文 UNIQUE 错误）。

**老师的日常**
- 姓名行菜单新增**「移出班级」**（归档：名单消失、历史台账保留、可恢复）——转学/毕业的学生终于能清掉。
- 破壳物种不再一律变猫（按学号轮转，与大屏一致）。
- 导入名单的小组列兼容「第2组 / 2组 / 二组」，不再静默变成 1 组。
- 台账默认看**今日**（以前默认"本堂课"，第二天打开显示 0 笔以为记录丢了）；「清空台账」改名「清空本页显示」。
- 经验阈值步长上限 500（以前手输 9999 也能存，20 级要 19 万经验）。
- 备份文件名带日期；空班引导改为指向「新增学生 / 名单导入导出」；大屏引导条删掉"点右上 +1"的空承诺。

## 安装

`ClassPet Setup 1.2.8.exe` 覆盖安装；数据仍在 `%APPDATA%\class-pet-desktop\classpet.sqlite`。
