# v1.2.6 · 2026-11-20

## 新增：自定义科目真正可用

注册时选「自定义」并填「综合」，现在会：

- 进入班级科目表（语文 / 数学 / **综合** 四个科目），**「综合」是主科且默认解锁**；
- 教师台学科按钮按班级科目**动态显示**（不再只有三个固定按钮），底部显示「综合课」；
- 该班新建学生时**自动为该科建宠物行**（蛋形态），可以正常赋分、破壳、升级；
- 其它科目仍锁着，等「综合」练到 Lv.20 后由老师自己选择解锁。

## 优化

- 「名单导入导出」弹窗精简：只保留「列顺序：学号, 姓名, 小组, 等级, 经验, 物种」

## 数据说明

- 自定义科目代码规则 `custom1/custom2…`（班内唯一），宠物行 `subj_custom1`；
- 老师在科目表里可继续新增自定义科（`addClassSubject`，会给班里已有学生补蛋态宠物行）；
- 老班级（只有三科）行为完全不变。

## 安装

`ClassPet Setup 1.2.6.exe` 覆盖安装；数据仍在 `%APPDATA%\class-pet-desktop\classpet.sqlite`。
