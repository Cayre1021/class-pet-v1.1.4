# v1.2.3 · 2026-11-20

## 新增

- **名单导入导出改为真 Excel（.xlsx）**：菜单「数据与设置 → 名单导入导出 · XLSX」
  - 导出：系统保存对话框，生成 .xlsx（中文不乱码、表头加粗、列宽自适应、冻结首行）
  - 导入：系统打开对话框，支持 .xlsx 与 .csv；旧版 .xls 会提示"请在 Excel 里另存为 .xlsx"
  - 台账导出同样改为 .xlsx
- **阈值步长两侧加 −10 / +10 按钮**：经验阈值弹窗里点一下就调，不用手动敲数字

## 修复

- **选数学就该能用数学**：注册时选的科目成为班级主科，**恒解锁**、可直接赋分；其它科目仍按链式解锁
- **改学号撞号不再静默改号**：以前把学号改成已占用的号会偷偷变成"最大号+1"并提示成功，现在会明确报"学号已被占用，未修改"
- **阈值不允许相邻相等**：以前可保存多个等级共用同一阈值（一次加分直接跳满级），现在会拒绝并说明原因
- **切班不再把上一班名单补写进当前班**（跨班串名单的隐患）

## 安装

`ClassPet Setup 1.2.3.exe` 覆盖安装；数据仍在 `%APPDATA%\class-pet-desktop\classpet.sqlite`。
