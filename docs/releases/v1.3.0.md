# v1.3.0 · 2026-11-21

## 修复（严重：加分后进度条不动 / 两页看着不互通）

**根因**：卡片和大屏显示的是「展示宠」（`students.display_pet_id`），而加分打的是「当前授课科目的宠物」。
新注册的班级（或导入的学生）展示宠常常停在语文那一只，于是：

- 老师在数学科加分 → 数学宠物经验涨了，但卡片显示的还是语文那只 → **进度条纹丝不动**；
- 教师台与大屏其实读同一只，所以两边「一起不动」，看起来像数据不互通。

**修法**：赋分时把展示宠切到**正在赋分的这只宠物**（谁加分跟谁），两页立即联动；
撤销时数值回滚、展示宠保持在当前科目。

## 验证

- `probe_exp_progress`：数学班 → 加分后进度条 0% → 10%，展示宠切到 `subj_math`，大屏显示同一只（5 EXP / 10%）
- `test_display_pet_follows_score` 8/8：数学加分跟数学、语文加分跟语文、撤销后数值回滚
