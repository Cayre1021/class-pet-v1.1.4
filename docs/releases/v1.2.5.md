# v1.2.5 · 2026-11-20

## 修复（重要）

**数学账号里语文仍然显示解锁**

- 原因：老班级的解锁集合迁移规则里写死了「语文」——迁移时无条件给每个班补了一条语文解锁，
  所以注册在修复之前的数学班，语文依旧亮着（英语正常是灰的）。
- 现在：
  1. 迁移只补「主科 + 真正用过（有已破壳宠物）的科目」，不再无条件给语文；
  2. 新增一次性订正：主科不是语文、且语文从未被真正用过的班级，**自动移除**那条错误的语文解锁；
  3. 真正用过语文的班级（有已破壳的语文宠物）保持不动，不会把正常班级锁死。

装好后：数学班进教师台，**语文与英语都应是灰的**；只有当已解锁科目练到 Lv.20，才会弹「新学科可以解锁了」，由老师自己挑。
