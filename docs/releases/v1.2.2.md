# v1.2.2 · 2026-11-20

## 修复（重要）

**注册新账号后串到别的班级 / 看到别人班的学生**

- 原因：V3 登录门户的「注册」只往浏览器本地写了一份档案，**没有在数据库里建班级**；
  而学生大屏/教师台是按"当前账号里的 classId"取数的，那份缓存还是上一个账号的 →
  新账号进来看到的是上一个账号（例如「试验班0930 · 许」）的名单。
- 现在：注册（以及"本机档案与当前账号不一致"时的登录）会**在数据库里新建一个独立空班级**：
  21 级阈值（破壳 50 / 每级 +100）、6 个形态阶段、三科、13 条默认规则，**名单为空**；
  并把新账号写入本地账号缓存，页面随之只显示这个新班级。
- 界面会提示「已为本机创建独立班级，名单为空，可直接录入学生。」
- 已存在的班级数据不受影响。

## 安装

`ClassPet Setup 1.2.2.exe` 覆盖安装；数据仍在 `%APPDATA%\class-pet-desktop\classpet.sqlite`。
