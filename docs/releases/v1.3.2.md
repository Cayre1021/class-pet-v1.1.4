## 修复：新注册班级里「移出班级」点了没反应

根因：弹窗传给后端的是页面序号（1、2、3…），不是数据库 id。
种子班恰好能对上（3 → st_03），但新注册班级的 id 是 st_17… 这种，序号对不上 → 更新 0 行且不报错，所以卡片纹丝不动。

修法：归档改用数据库 id（s.dbId）。实测新班：移出后卡片 3 → 2，库里恰好 1 人归档。

## 新增：已移出名单（可恢复）

之前说可恢复却没有恢复入口。现在「数据与设置 → 已移出名单」列出所有被移出的学生，
菜单右侧显示人数，点「恢复 xxx」即可放回名单（实测 2 → 3，库里归档清零）。
