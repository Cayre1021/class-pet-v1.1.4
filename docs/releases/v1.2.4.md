# v1.2.4 · 2026-11-20

## 修复（重要：学科解锁模型）

**数学账号不该一开始就能用语文**

- 之前「语文」被代码写死为"永远解锁"，所以任何班级都能赋语文。
- 现在：**开局只有老师注册时选的那一科解锁**；该科宠物练到 Lv.20 满级后，剩余科目才进入"可解锁"状态，
  由**老师在弹窗里自己选**要解锁哪一科（不自动、不按固定顺序）。
- 解锁状态落库（新表 `class_subject_unlocks`），老班级一次性迁移，保证没人被锁死。
- 被锁的科目：按钮显示锁、点它会被拒绝并说明原因；赋分前置校验同样拦截（页面绕不过去）。

## 其它

- 已解锁科目的"未破壳蛋"现在允许赋分（否则解锁后永远攒不到破壳经验）

## 安装

`ClassPet Setup 1.2.4.exe` 覆盖安装；数据仍在 `%APPDATA%\class-pet-desktop\classpet.sqlite`。
