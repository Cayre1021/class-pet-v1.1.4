# v1.2.7 · 2026-11-20

## 修复

**首次进入教师台时，赋分学科的滑块停在"上一个账号的学科"**

- 数学班进去滑块在「语文」、科学班在「英语」，都得手动点一下才对；
- 更糟的是自定义科（科学）没解锁前点它滑不过去，等于没法用。

原因：授课学科存在**全局单一键**里，从没按班级校正过。

现在：
1. 首进教师台，滑块自动落在**本班主科**（注册时选的那一科，自定义科也算）；
2. 学科按**班级分别记忆**：A 班选数学、B 班选科学，各自进来都停在各自的学科；
3. 解锁表按班级**科目表动态构造**，自定义科的解锁状态不再缺失；
4. 手动切科仍会持久化（并同时写全局键，学生大屏继续跟随）。

## 安装

`ClassPet Setup 1.2.7.exe` 覆盖安装；数据仍在 `%APPDATA%\class-pet-desktop\classpet.sqlite`。
