## 模式一：完整多智能体全栈重构提示词 (Full Team Prompt)

```markdown
你现在作为班级电子宠物管理系统的核心重构工程师。请根据工作区根目录下的两份基线文档：
1. 《班级电子宠物系统_全功能模块需求与产品逻辑提炼文档(PRD交接基线).md》
2. 《班级电子宠物系统_历史踩坑与必须严格规避的Bug红线清单.md》

在现有的 Electron 桌面应用架构与本地真实 SQLite 数据库基础上，进行全面的系统重构与质量修复。

### 核心任务与改造范围：
1. 【班级多学科数据模型重构】：
   - 彻底废除以教师单人号为主体的割裂设计，改以【班级空间】为核心实体，全科教师共享花名册。
   - 允许自定义科目（语文、数学、英语、科学、美术、体育等）。
   - 每门学科绑定独立电子宠物，彻底废除系统默认写死物种（强制绑狗、狐狸）的硬编码，破壳认领时由学生自主从 8 大物种库中挑选。
   - 赋分跟随当前授课教师的科任动态分流，支持多学科萌宠同时加分；单科达到 Lv.20 MAX 时触发“王者觉醒”，激活新学科萌宠蛋认领特权（比谁养成宠物多）。

2. 【学生大屏与卡片弹窗双排版实现】：
   - 学生卡片展示全量数据：学号（补零两位如 #01）、姓名、当前阶段立绘、学科、等级、分段升级进度条（当前级到下级）、多科状态微标簇与状态印章（请假/待破壳/可进化/MAX）。
   - 详情弹窗同时实现【折叠手风琴版】与【不折叠清晰分区版】双套方案以供对比评估。
   - 弹窗内必须支持“原地破壳认领”与“原地进阶确认”，杜绝强制退回大屏列表的割裂交互。

3. 【讲台一体机触控悬浮圆圈菜单】：
   - 弃用死板的底部横排 Dock，改为可拖拽悬浮小球（具备边界可视区安全吸附检测）。
   - 点击小球以等距极坐标向四周辐射展开 6 个二级功能圆圈（换风格、大屏排布、随机点名、屏幕下沉、卡片放大、教师控制台）及对应三级圆圈。
   - 展开后 10 秒无操作或点击屏幕空白自动收起防遮挡。
   - PK 竞速榜支持【横向赛道拔河】与【纵向柱状图看板】双向随时切换。
   - 尺寸缩放控件仅在卡片网格下显示与生效，切换到 PK 榜等模式自动隐藏或禁用。

4. 【教师操作台“指哪打哪”秒级赋分与精准审计】：
   - 核心体验做到 0.5 秒定位学生、1 秒完成加减分；坚决彻底剔除“抽选点名”。
   - 智能识别 Excel 表格导入名单，缺失学号自动生成 01, 02... 补零序号；支持考勤请假置灰防误加分。
   - 经验值设置极简化（提供 3 档推荐预设 + 线性参数快速生成），严格守卫“扣分不降级、不回退已解锁外观”铁律。
   - 支持单人精准穿透审计（点击学生直接单独调出该学生专属历史明细），支持误操作一键撤销（Undo）。

5. 【严格规避 32 项历史重大 Bug 红线】：
   - 必须通过自动化测试验证：串人 Bug 100% 根治（事件流锁定实体唯一 ID）、未破壳状态守卫（未破壳蛋坚决禁止加分）、日常互动防刷双铁律（单日 <= 5 EXP，累计 <= 课堂正向加分总和）、剔除假数据库连接等。

请先提供详细的重构改造计划与文件变更清单，并在本地通过 Git 建立规范里程碑后开始实施。
```

## 模式二：专注聚焦核心模块重构提示词 (Focused Team Prompt)

```markdown
你现在作为班级电子宠物管理系统的业务逻辑开发专家。当前任务为【单线聚焦核心模块重构】，集中修复痛点 Bug 并完成核心业务闭环。

请参考工作区根目录下的两份基线文件：
1. 《班级电子宠物系统_全功能模块需求与产品逻辑提炼文档(PRD交接基线).md》
2. 《班级电子宠物系统_历史踩坑与必须严格规避的Bug红线清单.md》

### 本轮聚焦的 4 大核心任务：
1. 【彻底根除串人 Bug 与未破壳加分漏洞】：
   - 排查全局升级监听与弹窗上下文，强制使用不可变的 studentId / petId 进行精准匹配，严禁通过数组索引推导对象。
   - 在赋分底层 Store 层与 UI 层建立前置守卫：对未解锁或未孵化的宠物蛋，坚决拦截加分并给出明确引导。

2. 【多学科独立经验与科任动态切换闭环】：
   - 改造数据结构，使每名学生名下的各门学科（语文、数学、英语及自定义科目）拥有独立的宠物实例、等级、经验与阶段。
   - 教师操作台与大屏顶部支持“当前授课科目”切换，加分操作精准落入当前学科萌宠。

3. 【卡片详情弹窗折叠版与原地破壳实现】：
   - 实现折叠手风琴版弹窗：常驻头部（姓名/学号/大组）+ 模块1当前学科主舞台（默认展开）+ 模块2多科管理（折叠）+ 模块3六大互动（折叠）+ 模块4现场加减分（折叠）。
   - 在弹窗内实现原地破壳与原地进阶，达成条件时原地亮起操作按钮，点击原地弹出选宠/进阶确认。

4. 【操作台单人穿透审计与一键撤销 (Undo)】：
   - 表格中点击单名学生行，直接调出该学生的专属历史审计明细。
   - 顶部常驻撤销按钮，支持秒级回滚最近一次操作批次。

请直接在本地现有 Electron 架构与 SQLite 基础上进行修改，并附上单元测试用例验证上述逻辑。
```
