## 1. P0 · 安装与启动（30 分钟）

- [ ] **便携版**双击即开，进入 V3 门户（标题「班级电子宠物 · 教师登录 / 注册」）
- [ ] **安装版**走完 NSIS 安装，桌面/开始菜单快捷方式可用
- [ ] 首次运行 Windows SmartScreen 提示（**预期会出现**：包未签名；点"更多信息→仍要运行"）
- [ ] 注册一个班级（班级 + 姓名 + 科目），进入「选择入口」
- [ ] 进「学生大屏」：图片全部显示，F12 控制台**没有红色报错**
- [ ] 进「教师操作台」：能看到学生名单（种子库是 88 人的演示班级），图片正常
- [ ] 关掉程序再打开：**仍在 V3 门户**，之前注册的班级/姓名还在
- [ ] 卸载后重装：用户数据是否保留（预期保留，在 `%APPDATA%\ClassPet\`）

## 2. P0 · 数据正确性（最容易被投诉的地方，40 分钟）

用「教师台」，随便挑一名学生，按顺序做：

- [ ] 加 2 分 → 提示必须出现「**班级库已确认**」；卡片经验和进度条立刻变化
- [ ] 立刻点「撤销」→ 经验回到加分前
- [ ] **撤完把程序关掉再打开 → 经验必须还是撤销后的值**（不能"复活"）
- [ ] 再点「撤销」→ 应提示"只能撤销本堂课最后一笔"或"没有可撤销的"
- [ ] 把授课科目切到「数学」→ **卡片上的宠物不能变**（只改赋分目标）
- [ ] 给数学还没破壳的学生加数学分 → 应被拒，并说明原因（未解锁 / 未破壳）
- [ ] 把某学生标记「缺勤」→ 给他加分应被拒；**重启后缺勤恢复默认**（当天开关，不落历史）
- [ ] 打开「台账」→ 能看到刚才那笔（时间/学号/姓名/规则/学科/分值/状态）；「本堂课」「今日」两档切换正常
- [ ] 改一个行为规则的名字（数据与设置 → 自定义规则）→ 赋分台按钮名字立刻跟着变
- [ ] 改「经验阈值」的每级步长 → 保存后进度条与升级门槛跟着变；重启仍生效
- [ ] 「编辑资料」：**等级、经验是灰的不能改**（只允许改姓名/小组）

## 3. P1 · 导入导出（30 分钟）

- [ ] 导出名单 CSV → 用 Excel 打开，中文不乱码
- [ ] 把某学生姓名改成 `=SUM(A1)` 再导出 → Excel 里应显示为文本 `'=SUM(A1)`（**不能变成公式**）
- [ ] 原样把导出的 CSV 导回去 → 名单、小组、物种不变；**库里没出现在文件里的学生不能被删掉**
- [ ] 导出 JSON 备份 → 用记事本/任何 JSON 工具能直接解析（不应有 BOM 乱码）
- [ ] 恢复这份 JSON 备份 → 提示成功；用错误文件（随便一个文本文件）恢复 → 应被拒且**数据一点不变**

## 4. P1 · 大屏与课堂体验（真机，30 分钟）

- [ ] 投影/大屏上**后排 3 米能读清**姓名与等级（这是主要投诉点，请如实说）
- [ ] 触屏点卡片、点赋分按钮、拖动悬浮球都跟手
- [ ] 卡片上按空格**不会**误触发"随机抽点"；空白处按空格才会
- [ ] 抽点、课堂计时器能用；**关掉计时器后不再响铃**（等 1 分钟确认）
- [ ] 主题切换：教师台换成「护眼森林」→ 去学生大屏，**主题应一致**
- [ ] 音效开关有效；音效关闭后确实没声音
- [ ] F11 全屏正常；Esc 能退出弹层且焦点回到你点的那个按钮
- [ ] 断网（拔网线）后三页仍可用、无外链请求

## 7. 红线（这几件事请不要做）

1. **不要手改 `database/classpet.sqlite`**；要试数据先备份，或新建一个空班级试。
2. **不要在仓库里提交** `node_modules`、`electron-app/release/`、用户数据库、真实学生信息。
3. **不要"恢复"教师台已取消的四个入口**（小组筛选 / 排序 / 缩放 / 移组）：这是已签决策 D1=A 的结果，不是遗漏。要改必须先有一份签署的覆盖记录。
4. 发现"看起来像缺陷"的地方，先查 `docs/V3_回归报告.md` 第四节「未验证」和 `docs/V3_前后端对齐表.md` 第五节「已知缺口」——**已知项不算新缺陷**，但仍请报，注明"已知"即可。
5. 不要把"AI 说通过了"当成验收结论；本单没打勾的就是没验。

## 8. 已知情况（避免重复劳动）

| 已知 | 说明 |
|---|---|
| 未签名 | 首次运行会有 SmartScreen 提示，属预期 |

## 10. 数据存在哪（给你和老师的定心丸）

- **成绩数据在数据库里**：`%APPDATA%\class-pet-desktop\classpet.sqlite`（学生、三科宠物经验等级形态、阈值、规则、赋分流水与台账）。
- **不是浏览器缓存**：实测把 localStorage 全清空，学生 88 人、经验 280、等级 Lv.8、阈值与规则全部还在（`tests/probe_storage_durability.cjs` 8/8）。
- 浏览器缓存里只有：身份（班级/老师）、主题、音效、缩放——**丢了不影响任何成绩**。
- 卸载重装、换机器登录都不会丢库；但**重装前请备份** `%APPDATA%\class-pet-desktop\classpet.sqlite`（卸载程序不会替你备份）。
- 老版本（只有本机缓存、库里还没数据）第一次打开会自动把名单迁进数据库，迁完清理本地镜像。
- 判定方法（出问题时用）：`%APPDATA%\class-pet-desktop\classpet.sqlite` 的修改时间在你操作后应更新。
## 11. 1.2.7 之后的验收口径（请按老师动线走）

数据路径更正：**`%APPDATA%\class-pet-desktop\classpet.sqlite`**（不是 `ClassPet`，早期文档写错了）。

按顺序走一遍，任一步不符合就是缺陷：

1. **注册**：预设科目（语/数/英）与**自定义科目**（如"科学"）各建一个账号；
2. **首进教师台**：学科滑块必须停在**该班主科**，底部显示"<科目>课"；其余未解锁科目带锁、点了被拒；
3. **导入名单**：用 `.xlsx` 导入 3 个学生（9901/9902/9903），再把一个学生的学号改成已占用的号 → 必须提示"学号已被占用"，不能偷偷改号；
4. **破壳**：给蛋加 49 分 → 显示进度、按钮灰；加到 50 → 可点「破壳孵化」；**点了才孵化**；
5. **赋分/撤销**：多选 5 人 +5 → 台账出现 5 条 → 撤销 1 次全部回滚；
6. **解锁链**：把主科宠物练到 Lv.20 → 弹「新学科可以解锁了」→ 自己挑一科 → 该科变可用；
7. **导出**：名单导出 `.xlsx`，用 Excel/WPS 打开中文正常、表头加粗；
8. **阈值**：用 ±10 调整步长 → 保存 → **重启**后数值一致；
9. **检查更新**：点「检查更新」→ 显示当前版本 v1.2.7 且提示已是最新（或列出新版本）；
10. **备份与还原**：导出 JSON → 删一个学生 → 还原 → 学生回来。
