# 教师一页手册（V3）

> 一页看完：怎么进、怎么加分、怎么撤销、怎么破壳、怎么看台账、怎么备份。
> 适用版本：V3 三页（学生大屏 / 教师操作台 / 门户），启动即进入 V3 门户。

## 1. 进入

1. 双击启动程序 → 进入 **门户页**。
2. 「教师登录」填 **班级 + 姓名**（注册过就直接登录；没注册先点「注册」页签，三项信息即可）。
3. 进入「选择入口」：**学生大屏**（投屏用）或 **教师操作台**（日常用）。

> 登录只比对本机档案，不联网、不要口令。想回到老门户口令流程，用 `CLASSPET_START_PAGE=portal_auth.html` 启动。

## 2. 加分 / 扣分（教师台）

1. 左侧点学生行（可多选，`空格` 勾选、`j/k` 上下移动）。
2. 右侧赋分台点规则按钮（+认真倾听 / +积极发言 / … / −小声提醒）。按钮由班级库的行为规则生成。
3. **看到「班级库已确认」才算真的加分成功**；若提示「无人可赋分 / 未破壳 / 未解锁」，说明这门课这个学生还不能加分，原因会写在提示里。

- 语文：蛋形态也能加分（攒破壳能量）。
- 数学 / 英语：要先破壳认领才能加分；解锁条件见第 4 节。
- 缺勤学生：先点「缺勤」开关（**当日有效，不写库、不留历史**）。

## 3. 撤销（教师台）

- 右下「撤销」按钮：**只撤最后一笔**。按钮灰色说明本堂课没有可撤的笔。
- 台账里只有最后一笔那一行带「撤销」按钮，其它行不能撤。

## 4. 破壳认领

- 学生大屏：卡片蛋形态 + 经验够了 → 详情里「立即破壳」。
- 教师台：编辑学生弹窗里也有「立即破壳」。
- 门槛：**经验达标**（默认 15 EXP，看班级阈值）+ **学科已解锁**（语文一直开放；语文满级后数学/英语二选一；第三门要另一门也满级）+ **学生未缺勤**。
- 破壳后该宠物自动成为这名学生的展示宠。

## 5. 台账

- 「数据与设置 → 台账」：两档范围**本堂课 / 今日**，可按学生筛。
- 每行：时间、学号、姓名、规则/事由、学科、分值、状态（已撤销会标出来）。
- 真实数据态的台账来自数据库，不是页面自己记的。

## 6. 学生管理

- **新增**：工具行「新增学生」→ 姓名 + 小组（学号可空，自动续号）；等级/经验由赋分产生，不能手填。
- **编辑**：行菜单「编辑资料」→ 只能改**姓名 / 小组**（等级、经验只读）。
- **删除学生请勿直接做**：会影响历史流水，按学校流程处理。

## 7. 规则与阈值

- **行为规则**：「数据与设置 → 自定义规则」可改名字和分值，保存后赋分台按钮立刻跟着变。
- **经验阈值**：「数据与设置 → 经验阈值」填「每级递增步长」：LV0=0、LV1=当前破壳门槛，之后每级比上一级多这个步长。保存后写入班级库并立即生效。

## 8. CSV 与 JSON 备份

- **导出名单 CSV**：Excel 直接打开（带 BOM）。以 `= + - @` 开头的名字会被加前缀 `'`，避免被 Excel 当公式执行。
- **导入名单 CSV**：按学号更新或新增学生，保留文件以外的学生。留空学号会新建学生并自动分配学号，同名允许。文件里出现等价学号（如 `1` 和 `01`）时，整份导入会被拒绝。等级和经验沿用班级库数据。
- **导出 JSON 备份**：整班快照（学生、宠物、阈值、形态、规则）。文件是标准 JSON，不再带 BOM。
- **恢复 JSON 备份**：会整班覆盖；版本不对、id 重复、阈值不合法都会被拒，**拒了就一点都不会改**。

## 9. 学生大屏（投屏）

- 4 列大卡、组带筛选与合计、点卡片开右侧检查器。
- 支持快捷赋分、抽点、课堂计时器、主题、音效、全屏。
- 悬浮球：抽点 / 计时 / 全班表扬 / 换肤。
- 大屏**没有撤销**（撤销请在教师台做）。

## 10. 常见问题

| 现象 | 说明 |
|---|---|
| 提示「只有最后一笔可撤销」 | 只能撤最近一笔，先撤后面的才能撤前面的 |
| 提示「【数学】尚未解锁」 | 语文还没满级（或第三门需另一门满级） |
| 提示「尚未破壳认领」 | 数学/英语要先破壳才能加分 |
| 提示「数据库未确认」 | 写入没成功，界面不会假装成功；稍后重试或检查磁盘 |
| 空班显示「本班还没有学生」 | 真实空态，不是故障；去「新增学生」或导入 CSV |
| 换页后主题回来了 | 主题存在本机共享键里，换页应保持；若没保持请记录当前页与操作顺序 |
