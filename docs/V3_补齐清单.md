## 二、对照标准，还缺什么

| # | 缺项 | 标准要求 | 现状 | 验收标准 |
|---|---|---|---|---|
| 1 | `PRD.md`（根目录） | 根目录必须有 | 只有 `docs/01_PRD_…` | 根目录一页 PRD：做什么/给谁/优先级/验收口径，指回 `docs/01` |
| 2 | `docs/api.md` | "前后端如何通信" | **完全没有** | 15 个 IPC 通道逐个写：入参 / 返回 / 失败情形 / 调用方 |
| 3 | `LICENSE` | 根目录必须有 | 缺 | 选定许可证并入库 |
| 4 | README 快速启动 | 前 20 行能看到 | 前 20 行是背景声明 | 前 20 行内出现：装依赖 → 启动 → 跑测试 三步命令 |
| 5 | 测试分层 | `tests/unit|integration|security|e2e` | 13 个脚本平铺 | 至少分出 unit（阈值/阶段/赋分）、integration（IPC→SQLite）、e2e（三页流转） |
| 6 | 数据边界 | 运行数据不提交；localStorage 只做缓存 | `database/classpet.sqlite` **已入库**；V3 入口页用 localStorage 存账号 | DB 移出版本库或明确标注为种子库；账号必须走 teachers 表 |
| 7 | 备份/回滚脚本 | 可复现 | 依赖手工备份 | `scripts/backup-db.(cmd|sh)` + 恢复步骤写进 README |
