# 学生大屏（design/v3_looseleaf_paper.html）· 视觉验收报告

> 验收对象：`design/v3_looseleaf_paper.html`（单文件，105 KB，宠物为真实 PNG，默认暖橙纸感）
> 验收环境：本机 Chromium 1248（headless=new），DPR=1，视口 1920×1080，中文系统字体，无网络
> 验收方式：真实浏览器渲染 + 真实鼠标事件（点卡片 / 点悬浮球 / 点赋分按钮 / 开弹窗 / 切主题 / 被 22 次点击推到升级），
> 每条结论都附计算样式、几何尺寸或滚动尺寸，不是目测印象。
> 证据目录：`design/review_shots/`（文件名见文末清单）
> 验收时间：2026-11-13

## 【结论】有 7 个问题（2 个明显、5 个轻微；无阻断）

---

## 逐项判定

### 1. 呼吸感 —— 通过
- 顶栏 72px；组带 `margin:24px 32px 0`、高 56px；组带底 152px → 网格区顶 176px，正好 24px；网格 `gap:28px`；卡片内边距 `12px 16px`。
- 三段间距落在 24 / 24 / 28px，节奏成立，没有"每块都描边"的堆叠感（描边只在卡片、组带胶囊、档案分段上）；唯一偏多的描边在档案面板内部，见问题 7。
- 首屏 1 秒内有一段引导气泡压在第 2、3 张卡片上方，见问题 6。

### 2. 3 米可读性 —— 通过（副行对比不足，见问题 3）
- `.card-name`：22px / 900 / 字距 0.66px，实测对比 18.6:1。
- `.pet-stage`：202px ÷ 卡片 320px = 63.1%（≥60% 达标）。
- `.lv-tag`：12px / 900 / 44×21px，位于卡片左上，不抢主体。
- `.card-no`（"#05 · 1组"）：13px / 700 / #8A8A86，对卡片底 #FFFDFA 的对比只有 3.41:1，3 米外基本糊掉 —— 问题 3。

### 3. 卡片五种状态 —— 通过
都不只靠颜色：
- 常态：2px 墨边 + 纸底；
- hover：`transform:translateY(-3px) rotate(.25deg)` + 双层投影（`0 7px 0` + `0 16px 26px`），有位移与阴影变化；
- 选中：3px accent 外环 + `translateY(-2px)`（有环、有位移）；
- 缺勤：`filter:grayscale(1)` + `opacity:.6` + `::before{border-style:dashed}`（灰度 + 虚线）；
- 蛋形态：蛋素材 + 3.8s 摆动 + 黄色"待破壳"标签（静态下靠图像与标签，摆动只在动态可见）；
- 满级：`::after{border-color:rgba(154,107,0,.85);border-width:2px}` 金色外框 + "★ LV.9 满级"。
蛋形态的静态区分完全依赖素材本身，若将来换成别的蛋图需复核。

### 4. 停靠式档案 —— 通过
- 选中后 `#content.has-ins`，`#pet-grid` 实测 `467.33px ×3`（3 列），`#inspector` 380×872 固定在 x1508–1888，没有任何卡片被压住。
- 380px 宽内「经验值 EXP」段（50/200 + 距升级 150 EXP + 进度条 + LV.5·第 3 阶段/25%）与「快捷赋分」段（5 颗 100×52 按钮 + 自定义组）纵向排布不拥挤；拥挤只发生在自定义组内部 —— 问题 2。

### 5. 赋分控件 —— 不通过
- `+1..+5`：100×52px，44px 以上命中区达标；
- `−` / `+`：28×52px，宽度贴着 ≥28×44 的下限，实际点起来偏窄；
- 中间"`5` + 自定义"：38×52px，数字 16px、副标签 10px（30×15 的文字盒），视觉上像一个只读值/标签，不像"给全部已选加该分值"的动作按钮；
- 三段重量失衡：上行 3 颗 100px、下行 2 颗 100px + 一个 94px 宽的三连控件贴在右边缘，第三列表头空出 —— 问题 2。

### 6. 弹窗 —— 不通过（随机抽点）
- 随机抽点：整屏蒙层 1920×1080，页面级无滚动条；但票面被抽签口压住、票面提示被完全遮住、舞台 12px 内容溢出被裁 —— 问题 1。
- 课堂计时器：`#mask-timer` 内无任何溢出元素（0 处滚动），圆环、1/3/5 分钟、"开始倒计时"、"重置"全部完整可见，按钮未被裁。
- 完整成长档案：600×485 弹窗，内部子元素全部落在 684–1236 的安全区内（左右各 24px），无裁切、无滚动条。

### 7. 烟花 —— 不通过
- `#fx` 全屏 canvas（`position:fixed;z-index:80;pointer-events:none`），绘制在卡片之上，但线径细、无实心遮挡，没有压住任何卡片文字（这点是对的）。
- 份量不足：9 发、每发 88–134 个粒子、线宽 2.0–4.2px、每帧 `rgba(0,0,0,.24)` 淡出，实测截图只是上半屏的零散细线，3 米外几乎注意不到；颜色为多色（FW_HUES 含 0/22/42/95/150/190/215/268/315）—— 问题 4。

### 8. 悬浮球 —— 不通过（轻微）
- `#fab` 64×64 固定在 (1832, 992)；与第 12 号卡片重叠 2688px²；档案打开时与面板右下角重叠 56×56px（压在面板圆角上，未压住"收起"按钮）。
- 展开菜单 212×160 出现在 (1676, 812)–(1888, 972)，`flipMenu()` 让它完全落在视口内，不会出屏 —— 问题 5。

### 9. 手绘滤镜 —— 通过
- 3 倍放大检查：墨线有 0.5–1px 的自然抖动，没有模糊、断线或重影；`.lv-tag` 有 `matrix(0.99961,-0.0279,…)` 的轻微倾斜，属于设计意图。
- 纸纹为 140×140 的 SVG 噪声（`opacity:.085`），不脏、不糊；
- `#111` 墨线对 `#FBF3EA` 纸底对比 18.6:1，2px 线宽读起来是"马克笔"，不像印刷错误。

### 10. 主题 —— 通过
- 只有 暖橙 / 护眼森林 / 晴空蓝 三套（`[data-theme-set]` 仅 3 个）。
- 实测三套主题的 `--accent` 分别 #B84B1B / #267853 / #2869A6，且同步驱动 `.lv-tag`、`.exp-meter i`、`.gchip.is-on`、`.score-btn`、卡片底色，没有发现残留旧主色。
- "成长档案"标题上的黄色荧光笔与"待破壳"标签的黄色在三套主题下都不变，属于固定语义色，非残留。

## 【问题 1｜明显】随机抽点弹窗：票面被抽签口压住、提示文字被完全遮挡、舞台溢出被裁
- 截图：`07_rollcall.png`、`19_rollcall_crop.png`（2.4 倍放大）
- 元素：`#mask-rollcall` → `#draw-stage` / `#ticket`（.ticket，z-index:2）/ `.slot`（抽签口，z-index:3）/ `#ticket-meta`
- 现象：`.slot` 132×44 贴在舞台底部（bottom:0）且 z-index 3，`.ticket` 是 z-index 2 且 bottom:16px，两者重叠 34px，票面下半（含 11.5px 的「点击下方按钮开始」）被抽签口的实心块与灰色横条盖死；同时 `.draw-stage{height:220px;overflow:hidden}` 的内容高度是 232px，被裁掉 12px。抽签进行/结果态票面上移 112px 后才可读（`08_rollcall_draw.png` 正常）。
- 期望：初始态票面文字与提示完整可见，票面在抽签口之上，舞台不裁内容。
- 建议 CSS：
  - `.ticket{bottom:52px;z-index:4}`
  - `.draw-stage{height:236px;overflow:visible}`
  - `.ticket{padding-bottom:6px}`（给 .tname 与 .tmeta 之间留 6px）

## 【问题 2｜明显】快捷赋分的自定义组：中间格像标签不像按钮，± 命中区偏窄，整组与上行按钮不对齐
- 截图：`03_selected.png`、`17_inspector_crop.png`、`18_quick_score_crop.png`（3 倍放大）
- 元素：`.cc-step`（−/+）、`.cc-apply`（中间值）、`.cc-apply .sub`（"自定义"）
- 现象：`.cc-apply` 38×52，内部"5"16px、"自定义"10px/30×15px；`.cc-step` 28×52；上行 `.score-btn` 是 100×52。中间格既没有"＋"号也没有按钮语气，10px 的"自定义"在 3 米外不可读，容易被当成"当前分值"的只读展示；三连控件总宽 94px 贴在最右，与上行 100px 网格错位。
- 期望：一眼看出"点它 = 给该生加 N 分"，± 好点，三连组与上行按钮视觉对齐。
- 建议 CSS：
  - `.cc-apply{min-width:56px;font-size:18px}`、`.cc-apply .sub{font-size:11px;letter-spacing:0;margin-top:1px}`
  - `.cc-step{min-width:44px}`
  - 让三连组横跨整行、与上方 5 颗按钮对齐：`.score-custom{grid-column:1 / -1;grid-template-columns:44px minmax(0,1fr) 44px;gap:6px}`（现有的 `.score-custom{display:grid;grid-template-columns:28px minmax(0,1fr) 28px;gap:3px}` 是这一条的直接改法）

## 【问题 3｜轻微】卡片副行与赋分按钮副标签的对比度不足
- 截图：`18_quick_score_crop.png`、`01_initial.png`
- 元素：`.card-no`（"#05 · 1组"）、`.score-btn .sub`（"加分"）
- 现象：两者都是 `color:var(--ink-3)` = #8A8A86；13px/700 与 11px/800，对卡片底 #FFFDFA 的对比分别 3.41:1 与约 3.4:1，低于 WCAG AA 小字号 4.5:1；3 米外这两行基本消失。
- 期望：副信息仍弱于主信息，但可读。
- 建议 CSS：`.card-no{font-size:14px;color:#6E6E69}`、`.score-btn .sub{font-size:11.5px;color:#6E6E69}`（#6E6E69 对 #FFFDFA 约 4.9:1）

## 【问题 4｜明显】升级烟花份量不足，喜庆感弱
- 截图：`10_levelup.png`、`10c_levelup_late.png`
- 元素：`#fx`（canvas）与 fireworks/fwSpark/fwLoop 参数
- 现象：9 发爆炸点分散在画面上半部，但每发只有 88–134 个线宽 2.0–4.2px 的细线粒子，每帧以 `rgba(0,0,0,.24)` 擦除，轨迹留存极短；截图里只剩零散绿/紫/黄细线，屏幕上半部没有被"点亮"的实感。
- 期望：升级瞬间上半屏明显被彩色覆盖，且不遮挡卡片文字与姓名。
- 建议（canvas 参数，无对应 CSS 属性，唯一落地方式在这里）：
  - 粒子线宽 `p.w = 2.0 + Math.random()*2.2` → `3.2 + Math.random()*2.6`
  - 每发粒子数 `88 + rand*46` → `130 + rand*60`
  - 尾迹淡出 `rgba(0,0,0,.24)` → `rgba(0,0,0,.12)`
  - 若只想动 CSS，可加 `#fx{filter:saturate(1.2)}` 提亮，但改善有限。

## 【问题 5｜轻微】右下悬浮球与卡片、档案面板同时压边
- 截图：`01_initial.png`、`03_selected.png`、`06_fab_menu.png`
- 元素：`#fab` / `#fab-menu`
- 现象：球体 64×64 固定在 (1832,992)，与第 12 号卡片重叠 2688px²；档案打开时与面板 (1508,176,1888,1048) 的右下角重叠 56×56。菜单本身安全（在视口内）。
- 期望：球体落在没有信息的位置，或最后一行卡片让出球位。
- 建议 CSS：`#grid-scroll{padding:12px 4px 88px}`（末行让出球位）；`#fab{right:24px;bottom:24px}`；档案打开时把球抬高到面板下方空白 `#content.has-ins .fab-wrap{bottom:96px}`，避开面板右下角。

## 【问题 6｜轻微】启动引导气泡压住网格
- 截图：`01_initial.png`（加载后约 1 秒）
- 元素：`.coach`（`showCoach(3000)`）
- 现象：气泡 520×72 固定在 `top:calc(72px+56px+34px)` 居中，正好压在第 2、3 张卡片顶部（含第 3 张的 LV 标签区域），持续 3 秒；气泡底色 #FFF8E1 与纸底接近，第一眼像卡片内容而不是浮层。
- 期望：引导不遮挡卡片信息。
- 建议 CSS：`.coach{left:auto;right:32px;top:96px;transform:translate(0,-8px)}`、`.coach.is-on{transform:translate(0,0)}`（挪到组带右侧的空白区，仍保持 z-index:65）；若要保持居中，则 `.coach{top:calc(72px + 56px + 8px);max-width:min(720px,60vw)}`，并确保底部只覆盖在组带与网格之间的 24px 空隙上。

## 【问题 7｜轻微】档案面板内部每段都描边，同屏四层线条
- 截图：`17_inspector_crop.png`
- 元素：`.ins-sec::before`（1.5px 墨边）、`#inspector`、`.pet-card`、`.gchip`
- 现象：面板整体 2px 边框 + 面板内"宠物卡 / 经验值 EXP / 快捷赋分"三段各 1.5px 墨边，再加卡片自身的 2px 墨边，同屏出现 3–4 层闭合描边，比网格区更"吵"。
- 期望：段落仍可区分，但少一层闭合框。
- 建议 CSS：`.ins-sec{border-radius:10px 8px 12px 9px}` 保留，改为只画分隔线：`.ins-sec::before{border:0;border-top:1.5px solid rgba(17,17,17,.18);border-radius:0}`；或 `.ins-sec:first-child::before{border:0}`。

## 【无法判断】
- 动效节奏（hover 抬起 120ms、选中 160ms、烟花 1.2–2s）是否"顺手"，静态截图无法判断，需要录屏或真机。
- 音效（`sfx('select')/sfx('bell')`）的音量与音色。
- 悬浮球拖拽手感与贴边停靠行为（需要真实拖拽操作）。
- 烟花的完整演出（起飞 → 爆炸 → 消散）是否够喜庆，需要录屏。
- 3 米实际可读性：需要在教室投影/电视上按真实亮度与观看距离复核（本报告只能给出 22px/900、63% 主图占比这类代理指标）。
- 纸纹与墨线在不同显示器色温/伽马下的观感（#111 对 #FBF3EA 的 18.6:1 在低亮度屏上可能偏硬）。

## 复现方式
1. Chrome 打开 `design/v3_looseleaf_paper.html`，DevTools 设 1920×1080、DPR=1。
2. 初始 → 点任意卡片 → 点右下悬浮球 → 随机抽点 → 开始抽点 → 课堂计时器 → 给同一名学生连点 +5 至升级 → 工具菜单切三套主题。
3. 实时自检：页面脚本暴露了 `__v3audit` 契约（`design/V3_DESIGN_SPEC.md`），可用它复核尺寸类断言。
