# V3 高保真页面设计规格（学生大屏 / 教师操作台 / 纸感变体）

> 本文件是三个页面唯一的视觉与交互契约。三个页面各自独立成文（单文件 HTML，内联 CSS/JS，无构建、无外网请求），
> 但必须遵守同一套 token、同一套层级、同一套自检契约，用户才能横向对比"结构"而不是"换色"。

## 0. 素材与硬约束

- 宠物素材（相对 `design/` 目录，必须原样使用真实素材，禁止用 emoji 代替主视觉）：
  - `../electron-app/src/assets/pets/{species}/{species}-stage{n}.png`，species ∈ cat, dog, bunny, hamster, bird, deer, fish, fox；n ∈ 1..5
  - 蛋：`../electron-app/src/assets/pets/shared/egg.png`
  - 爪印：`../electron-app/src/assets/decor/cat-paw.svg`、`dog-paw.svg`
- 禁止任何 `http://` / `https://` 资源（字体、图标、CDN 一律内联或系统字体）。图标全部用内联 SVG 或 Unicode。
- 模拟数据必须在页面上显式标注"模拟数据 · 演示原型"，不得冒充真实班级数据。
- 禁止删除功能入口（CONSTRAINTS.md §2）：所有控件即使被收进抽屉/菜单，也必须带中文文字标签，一次点击可达，并在自检中登记。
- 画布基准：1440×900 与 1920×1080 都必须无纵向滚动条、无横向溢出。

## 1. 审校结论：保留 / 去掉 / 新增

### 学生大屏

**保留（已确认的优质呈现，不得改动本质）**
1. 每行最多 4 列、宠物大图占卡片高度 ≥60%、姓名 20px+ 粗体（3 米可读）。
2. 点选学生 → 展开完整成长档案：大宠物图、学号/组别、等级与 EXP 进度、三科学阶、印章墙、赋分与互动按钮、破壳区。
3. 右下角可拖动悬浮球 + 位置记忆 + 工具菜单（抽点、计时器、全班表扬、换肤）。
4. 小组筛选与小组累计 EXP、学号升序 / 等级·经验降序两套排序。
5. 宠物森林网格 ↔ 4 大组座位表双视图。
6. 4 套主题（经典 / 暖橙 / 护眼森林 / 晴空蓝）、音效开关、全屏、重置。
7. 缺勤（灰度虚线）、蛋/待破壳、满级状态、统一 Toast。

**去掉（给排版增加冗余的点）**
1. 三级小组信息重复：头部 chips（8人·0EXP）+ 4 张组卡横栏 + 状态栏 → 合并为**一条组带**。
2. 常驻的 `💡 3米远距大字大图…` 教学文案 → 改为 3 秒自动淡出的首次 coach-mark，可由 `?` 重新唤起。
3. 双标题（大标题 + 副标题 + 演示徽标 + 状态栏标题）→ 只留一处标题 + 一行淡信息。
4. 头部 13 个控件平铺 → 只常显"视图分段 + 排序 + 工具"，其余进工具抽屉（保留文字标签）。
5. 卡片上的装饰性角标堆叠（学科微标、状态点、无序印章）→ 每张卡只保留 1 个语义角标。
6. 遮罩式右抽屉（盖住右侧一列卡片）→ 停靠式检查器（不盖卡片、无遮罩、可连续点下一个学生）。

**新增（呼吸感与交互）**
7. 组带：分段控件同时承担筛选与统计（人数 + EXP + 迷你条）。
8. 卡片右上角常驻「+1 表扬」快捷键（28px，hover 实体化）：课堂上最高频动作不必开面板。
9. 卡片级即时反馈：数字滚动、+N 浮字、粒子飞向进度条、卡片 pulse、进度条 shimmer。
10. 升级特效：全屏烟花 + 宠物 stage 图交叉淡入 + 姓名冲击波 + 边缘闪光 + 合成音效。
11. 破壳、盖章、抽点、计时的专属动效（见 §5）。
12. 键盘：`Esc` 收起检查器、`←/→` 相邻学生、`Space` 抽点启停、`1/2/3` 快速赋分（面板打开时）。

### 教师操作台

**保留**：四组泳道名册、全班/1-4组/归档筛选、搜索、列表缩放、新增、全选/清空、移组、快捷赋分、自定义规则、静音扣分、撤销、台账、Excel、经验阈值、备份、学生日志/编辑/归档、学科切换、直达学生大屏、返回门户、四主题。

**新增**：右侧常驻赋分台（与选中行相邻）、常显组分段、批量操作条仅在有选中时出现、快捷键、选中行 sticky 镜像、空态与失败态文案。

```css
  /* 学科 */

  /* 线、圆角、阴影 */
  --line:2px; --line-soft:1.5px;
  --r-card:14px; --r-btn:10px; --r-pill:999px;
  --shadow-pop:0 4px 0 var(--ink);         /* 浮起元素 */

  /* 字号 */
  --t-xs:12px; --t-sm:13px; --t-md:14px; --t-lg:16px; --t-xl:20px; --t-2xl:24px; --t-3xl:28px; --t-name:22px;
}
```

- 主题 4 套：`data-theme="classic|orange|forest|ocean"`，切换 `--accent / --accent-soft / --paper / --canvas / --surface / --surface-2`；ink 与学科色不变。
  surface 必须跟随主题，否则绿/蓝纸面上会残留暖白卡片与暖橙标题条。
  classic: accent #4F7C3A / soft #E6F0DC / paper #F4F3EF；orange: #B84B1B / #FBF3EA；forest: #267853 / #EFF6EF；ocean: #2869A6 / #EEF5FB。
  classic 与 forest 必须保持不同主色（曾同为 #267853，切换后几乎无差别）。
- 主题切换 160ms 过渡，切换时右下角播放一次色板波纹。
- 边框三级制：页面级 0 边框；面板/卡片 `2px solid var(--ink)`；行内元素用 `1.5px` 或 `border-bottom: 1px solid rgba(17,17,17,.12)`。**禁止**在每个嵌套容器上写 3-4px 边框。
- 阴影只给"真的浮起"的元素（悬浮球、菜单、抽屉、选中卡）。

## 5. 纸感变体（`design/v3_looseleaf_paper.html`）

- 视觉语言：手绘线稿 + 纸张纹理。参考 Looseleaf（shadcn 的"手绘纸质"组件库）的**做法**而非复制代码：1.5px 墨线、轻微不均的描边（SVG `feTurbulence`+`feDisplacementMap` 滤镜，静态不闪烁）、纸张噪点底纹、便签胶带、印章、马克笔高亮斜块。
- 字体：系统字体 + `font-family: "Segoe UI", "Microsoft YaHei"`；标题可用 `letter-spacing` 与略倾斜（`transform: rotate(-1.2deg)`）制造手写感，**不许加载外网字体**。
- 结构与学生大屏 v3 完全一致（同一套组带、4→3 列停靠检查器、悬浮球），只换视觉语汇；数据样本与前两页相同（32 人 / 8 种宠物 / 同名同分），保证可对比。
- 交互反馈全部换成"纸/戳"语汇：赋分 = 盖章落下 + 墨点；升级 = 手绘烟花（粗墨线放射）+ 贴纸弹出；抽点 = 纸条抽签 + 拍桌震动。

## 6. 动效规格（三页同源，用 Web Audio 合成音效，禁止外链音频）

| 事件 | 必须有的表现 | 时长 |
|---|---|---|
| +EXP | 数字滚动 → `+N` 浮字 → 3-5 颗粒子沿贝塞尔飞向进度条 → 卡片 pulse → 进度条 shimmer | 600ms |
| 升级 | 全屏 canvas 烟花（两层爆发，`pointer-events:none`）→ 宠物 stage 图交叉淡入 → 姓名冲击波圆环 → 边缘 vignette → 上行琶音 | 1400ms |
| 破壳 | 蛋 3 段抖动 → 壳碎片飞散 → 宠物弹性放大 | 1200ms |
| 盖章 | 印章 1.4× 旋转落下 → 墨点扩散 → 卡片轻震 | 420ms |
| 抽点 | 名字卷轴高速滚动 → 减速 → 定格 → 聚光灯 + 彩带 | 1800ms |
| 计时 | SVG 环形进度；最后 10s 红色脉动 + 结束三声铃 | — |
| 主题切换 | 160ms 变量过渡 + 右下角色板波纹 | 600ms |
| 排序/筛选 | FLIP 位置过渡（`transform`，不用 `top/left`） | 260ms |
| Toast | 底部中间滑入，不改变任何布局 | 300ms 进出 |

- 全部 `prefers-reduced-motion: reduce` 时降级为静态反馈（颜色/描边变化 + Toast）。
- 音效必须可关，状态存 `localStorage`。

## 7. 遮挡与层级合约（审查硬门槛）

z-index 阶梯（不得越级）：
`内容 0-9` → `选中卡 10` → `悬停卡 11` → `检查器 20` → `组带 25` → `顶栏 30` → `悬浮球 40` → `悬浮球菜单 45` → `弹窗遮罩 55` → `弹窗 60` → `coach-mark 65` → `Toast 70` → `烟花/粒子 canvas 80（pointer-events:none）`。

规则（自检会逐条查）：
1. 检查器用 grid 列占位，**不得**用 `position:absolute/fixed` 覆盖网格；面板打开时任意卡片的中心点必须 `elementFromPoint` 命中卡片自身或其后代。
2. 任何 `position:fixed` 装饰层（烟花、粒子、彩带）必须 `pointer-events:none`。
3. 关闭弹窗/菜单后必须真正移除遮罩（`hidden` 或 `display:none`），不得只改透明度，留下不可见的点击拦截层。
4. 下拉/弹出菜单贴边时必须翻转（右：`right:0`；下：`bottom:100%`），且 bbox 完整在视口内。
5. 网格滚动容器 `padding-top ≥ 12px`，hover `translateY(-2px~-4px)` 与 `box-shadow` 不得被 `overflow` 裁切。
6. 悬浮球 bbox 不得覆盖任何可点击元素的中心点；若与最后一排卡片/组带重叠，需在自检报告中列出（可拖动视为可接受，但报告必须可见）。
7. 1440×900 与 1920×1080 下文档本身不得纵向滚动（`documentElement.scrollHeight <= innerHeight + 1`）；允许**网格/泳道区域内部**滚动，但滚动条必须可见且不遮挡卡片内容。

## 8. 自检契约（三页都必须实现）

```js
window.__v3audit = function(){
  return {
    page: 'student' | 'teacher' | 'paper',
    controls: [{id, label, visible, clickable, centerHit}],   // 所有带文字标签的控件
    occluded: [{selector, coveredBy}],                         // 中心点被别的元素挡住
    clipped:  [{selector, byContainer}],                        // 超出最近滚动容器
    overflow: {scrollH:number, innerH:number, scrollW:number, innerW:number},
    consoleErrors: [],
    pass: boolean
  };
};
```
- URL 带 `?audit=1` 时自动执行一次，把结果写入 `window.__v3auditResult` 并 `console.log('V3AUDIT', JSON.stringify(result))`。
- `pass` 为 false 时必须能定位到具体 selector（这是给审查用的问题清单，不是装饰）。
