## 可复制正文

你是一名资深 UI/UX 验收工程师。我会给你「班级电子宠物系统 · 学生大屏」高保真原型的截图（单文件 HTML，断网可开，宠物为真实 PNG 素材，默认暖橙纸感主题）。请只做视觉与交互可用性验收。

### 背景事实（不要当成问题）
- 这是课堂大屏：学生会看，老师会点。3 米外要能读清姓名与等级。
- 分组信息集中在顶部「组带」（人数 + EXP），点击即筛选；没有座位表视图、没有卡片上的「+1」、没有三科学阶、没有印章墙、没有帮助按钮——这些是用户明确要求删掉的。
- 右侧成长档案是**停靠式**的：选中学生后网格从 4 列变 3 列，不覆盖任何卡片。

### 逐项判定（每条都要给结论）
1. **呼吸感**：顶栏 / 组带 / 网格三段的间距是否成节奏（16 / 24 / 32px 级别）；卡片之间 28px 左右的留白是否均匀；有没有"每块都描边"造成的噪音。
2. **3 米可读性**：姓名是否 ≥22px/900 且对比足够；宠物主图是否占卡片高度 ≥60%；LV 角标是否清晰但不抢主体。
3. **卡片五种状态**是否一眼可分且不只靠颜色：常态 / hover / 选中（应有描边或位移，不只是变色）/ 缺勤（灰度+虚线）/ 蛋形态 / 满级。
4. **停靠式档案**：选中后网格是否真的变成 3 列、卡片有没有被面板压住、面板 380px 宽度里「经验值 EXP」+「快捷赋分」两段是否拥挤。
5. **赋分控件**：`+1 +2 +3 / +4 +5 / [−][5][+]` 这一组；− 与 ＋ 是否好点（≥28×44 命中区）；中间数字是否**一眼看出是"给分按钮"**而不是输入框；三段的视觉重量是否平衡。
6. **弹窗**：随机抽点与课堂计时器两个弹窗，截图里**不得出现任何滚动条**；内容是否完整、按钮没有被裁掉。
7. **烟花**：升级截图里烟花是否够大够明显（应覆盖屏幕上半部相当面积）、是否多色、是否完全不遮挡 UI（不能压住卡片文字）。
8. **悬浮球**：右下角球体是否与最后一行卡片/组带有视觉冲突；展开菜单是否可能出屏。
9. **手绘滤镜**：墨线描边是否有模糊、抖动、断线；纸纹是否脏；暖橙底色（#FBF3EA）与墨线（#111）对比是否过重、像印刷错误。
10. **主题**：只保留 暖橙 / 护眼森林 / 晴空蓝 三套；切换后是否有明显不协调的残留色（例如按钮还是旧主色）。

### 输出格式（严格）
```
【结论】通过 / 有 N 个问题
【问题 1】截图区域 + 元素（CSS 选择器或文字标签）+ 现象 + 期望 + 建议修改的 CSS 属性
【问题 2】…
【无法判断】需要录屏/交互/更多角度才能定的项
```

### 边界
- 允许建议改：间距、字号、字重、颜色、圆角、描边粗细、阴影、层级、动效时长、按钮尺寸。
- 不许建议删功能入口或改信息架构（停靠档案、组带、悬浮球都是已定稿结构）。
- 每条建议必须落到具体 CSS 属性，不要写"整体更有呼吸感"这种无法执行的话。
